## 2026-07-13 · 六/七轮反馈:跪姿定稿 + 蹲行升级为双骨 IK
- 跪姿前腿修正:脚收回膝盖正下方(小腿竖直;因小腿27>大腿20,膝略高于髋是几何必然)——用户确认跪姿通过。
- 蹲行"屈腿碎步没有蹲感"→ 根治方案:**双骨骼 IK**。髋钉在跪姿同一低度(26),直接指定双脚目标(贴地、水平±24px 往返、迈步腿微抬 5px),用 IK 反解大小腿角度。效果=前伸腿伸展、收回腿深折臀下,腿形大反差+髋低=明确的"蹲着潜行"。方法论:FK 手调角度猜姿势不如"指定脚该在哪、反解角度"。CharacterRig 新增 _legIK(双关节解析解,膝恒朝前)。
- 蹲步周期 96(与 ±24 跨步几何匹配)。

## 2026-07-13 · 四轮试玩反馈落地(M1.8):下蹲定稿为"双姿态"
- 用户反馈:①蹲姿改军人单膝跪;②蹲行"脚上下抖不是前后走"。
- 病根:跪/深蹲基准里大腿近水平,在其上做角度摆动时膝盖走竖直弧线 → 脚上下动。
- **定稿方案=双姿态**(横版射击类通行做法):静止=单膝跪(前膝抬起小腿近垂直踩地/后膝点地小腿后折贴地,髋降22/前倾10°);移动=低姿行走(大腿绕竖直方向±26°前后摆+膝盖常弯35°基准,髋降14/前倾15°)——绕竖直摆腿则脚自然前后走;两姿态按移动强度(gaitIntensity)平滑混合,停步自动落回跪姿。
- 验收截图:跪姿(前膝立/后膝点地/持枪前倾)✓ 蹲行(清晰前后跨步,贴掩体与机器人对枪)✓。

## 2026-07-13 · 三轮试玩反馈落地(M1.7)
- **站立步态回退到经典正弦版**(用户拍板定版,CharacterRig 内已注明勿再改动数学形态):34° 正弦摆腿+55° 摆动相踢小腿,周期 150px;保留倒退反放与 0.78 步幅收缩。教训:二次谐波/步频对齐那版用户不买账——手感审美以用户为准,技术上"更正确"不等于"更好看"。
- **下蹲姿态重做**:旧姿势是"前弓步+后跪"的怪姿势(两腿基准角割裂)。新姿势=坐踞式深蹲:髋部下沉 28px、躯干前倾 16°、大腿近水平、前脚踩地/后脚跟收臀下,剪影约为站立的 2/3。
- **蹲行改真鸭步**:围绕深蹲基准做 ±20° 大幅交替迈步,小腿在迈出相伸展 38~45°,静止时回归纯深蹲——解决"两腿一个姿势只有轻微摆动"。
- 验收截图:蹲姿贴掩体箱、机器人曳光弹被箱子挡下、双腿一前一后鸭步中——机制/姿态/掩体三合一成立。FPS 166。
- **敌人穿掩体**:根因=敌人没有水平碰撞(只有巡逻范围 clamp)。给敌人加了与玩家同款的实体碰撞(单向平台除外),巡逻中被挡自动折返;掩体箱#1 挪到巡逻区外(680)。
- **下蹲改切换式**:单击 S 蹲住、再击站起(头顶需净空);蹲姿按跳=先快速起身(crouchT 加速 26/s 收缩)、起身过半(<0.45)自动起跳——实测从按键到离地约 40ms 的可见起身过渡,非瞬移机械跳。
- **步态去机械化**:①根因=步频与地速不匹配,脚底打滑(旧周期 150px/循环 vs 腿摆幅只能支撑约 104px)→ runCycleLen 104,相位改由带符号位移增量驱动(支持变周期不跳变);②摆腿加入二次谐波(0.82 基波+0.18 倍频),摆动腿快收、支撑腿慢蹬,消除钟摆感;③膝盖折叠加幂次(^1.4)更有弹性。
- **蹲行小碎步**:下蹲基准姿态上叠加 11° 小幅摆腿+膝部微动,周期缩短到 58px,髋部小幅起伏;与站立步态按下蹲程度平滑混合。
- 验收:单击蹲/起 ✓ 蹲跳 40ms 起身过渡(轨迹采样)✓ 倒退相位反放 ✓ 实战截图(机器人开火/掩体阻挡/激光瞄准)✓ FPS 166 ✓。

## 2026-07-13 · M1 代码审查(workflow)与修复
- 审查方式:3 个 sonnet 审查员(物理/生命周期/玩法数学)+ 1 个 opus 对抗性复核,6 条候选确认 5 条。
- **[HIGH] ragdoll 关节锚点错误**:Matter 的 Constraint 创建时记录 body 角度、求解时按增量旋转锚点,故 pointA/pointB 应传"创建时刻的原始世界偏移";此前多做一次反旋转导致非零角度部件死亡瞬间被求解器甩飞。修复后实测:尸体部件最远距躯干仅 46px(修复前散落上千 px),自然瘫倒。
- [MED] 巡逻折返"太空步":身体朝向跟着限速的瞄准角转,跟不上瞬时反向的移动 → 巡逻态朝向直接用移动方向。
- [MED] 悬浮平台净空 68px < 玩家 88px,在地面路径上形成"隐形墙" → 改为**单向平台**(oneWay:从下方/侧面穿过,只接从上方落下;地面和墙仍是实体)。实测:出生点直跑无阻挡、平台下起跳可穿越并站上平台顶。
- [LOW]×3:gibBodies() 每子弹重建数组(外提到帧级)、死亡敌人仍每帧算 LOS(跳过)、瞄准近垂直时朝向逐帧抖动(12px 死区迟滞)。
- 排障补充:又一次"输入失灵/更新停摆"仍是**窗口被遮挡后浏览器把游戏循环节流到 1Hz**,拉回前台立即恢复;正式做移动端时要接 Phaser 的 blur/focus 暂停逻辑。

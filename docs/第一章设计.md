一条连续长带(约 10000px,四段),段间**闸门**分段:清掉本段敌人或完成机关才开门。过门=**检查点**(自动存档+死亡重生点前移)。不做场景切换——尸体与断肢零件留场跨段(招牌爽点不清场),镜头连续无加载断点。

## 三、机关环节(用户拍板 2026-07-15)

1. **激光栅栏时序穿越**:红色激光束周期开合,蹲/跳/走位掐时机通过;触碰掉血+击退。视觉与游戏的红激光语言一致。
2. **多层封锁房间战**(本章大型机关):进入房间触发封锁——**所有门关闭**+警报红光;房间为**多层结构**,**升降梯**可到达任意一层;逐层清剿敌人;最终抵达**操作台**交互,解除封锁打开所有门。
3. **增味(已定案 2026-07-15,两条都要)**:打掉配电柜(已有 prop_cabinet 切件)可瘫痪对应一段激光栅栏=战斗解 vs 操作解二选一;封锁期间全场红灯频闪+警报音(复用背景动效层)。

### 封锁房间战详设"检疫区 QZ-03"(2026-07-15,用户要求做大做富)

**调研要点**(The Level Design Book/Barclay 等):封锁竞技场=玩家跨过场中线才触发、门在身后关(承诺感);进场一瞬要读出全场结构(边界清晰、别过繁);波次必须预告,目标/激励要引导玩家用满全场;竞技场后接冷却段(节奏峰谷)。

**空间**(约 1950×540,四层):
- F0 地面 / F1 y362 / F2 y258 / F3 y154(层距 104>跳高 92,垂直交通=双升降梯 E1/E2 全程往返+箱子搭跳的备用爬法——集装箱上 F1、弹药箱上 F2,多路线原则)。
- 层板为分段桁架(单向),在两个升降梯井处留槽;入口/出口闸门上方加"门塔"实体墙封顶,防从高层翻门逃逸。
- **操作台在顶层 F3 中央**(封锁期间锁定,标签"⚠ 封锁中:肃清残敌"),清完波次才解锁→按 E 开双门+警报解除+存活炮塔断电。
- 入口前(x2500)与出口后(x4540)各一检查点;封锁中死亡=房间整体重置(敌人清除/门重开/波次归零),避免锁死。

**威胁阵容**:
- **壁挂机枪炮塔×3**(本次实现):贴墙装甲基座+可旋摆双联枪体;慢速跟瞄+点射,可被打爆(hp40),封锁解除时断电;高中低三个射界交叉。
- 机器人巡逻兵:三波共 ~12 台,逐波从不同楼层刷入(刷入点闪光电火花预告),逼玩家换层。
- **腐蚀喷吐怪(待实装)**=生物B裂颚甲壳的远程形态:四瓣颚张开喷**绿色发光腐蚀弹**(抛物线,落地短暂腐蚀渍)——红线合规:发光能量酸,非血液体液。
- **生化服电磁枪兵(待实装)**=新人形敌人管线(人类第三阵营):防化服+电磁枪(蓝白电弧弹,命中短暂迟滞玩家);人类敌人死亡=瘫倒 ragdoll,不断肢无血(同玩家待遇,红线合规)。
- 波次配置全 JSON 化,喷吐怪/电磁枪兵实装后直接填进第 2/3 波。

**氛围**:封锁=全屏红光脉动+双音警报循环+HUD 状态条("封锁中·第X/Y波·残敌Z");解除=绿灯+解除音+toast。

## 四、生物类敌人(定案:三形态全采用,2026-07-15)

- **体态**:两足前倾(复用人形 IK 步态骨架;尾/触须用 arm_back 摆动槽位)。近战:快速逼近+扑咬,与机器人远程形成互补压力。
- **三形态角色分工**(数值待试玩调):
  - **A 无头胸眼=标准型**:中速冲脸+扑咬,第②段培养舱大厅首秀主力;
  - **B 裂颚甲壳=重型**:血厚速慢,冲撞压制,封锁房间战精英(少量);
  - **C 触须皮膜=敏捷型**:速度最快血最少,跳扑偷袭,后段与 A 混编。
- 母本:docs/风格参考/ai候选/生物候选A/B/C(已拍板);切件顺序 A→C→B(按出场顺序)。
- **外观**:猎奇外星实验体(培养舱逃逸叙事),苍白肉色+青绿生物发光(与舱液同色系)。
- **红线**(CLAUDE.md):不断肢、无体液;死亡=瘫倒(ragdoll)后消散为能量光点;猎奇≠血腥,无伤口内脏。

## 五、章末 BOSS:重型装甲兵(用户口述定版 2026-07-15)

- **体格**:大体积重装机兵(机器类,断肢照常且零件更大);**大质量落地震屏**在它身上兑现(后备清单)。
- **常规攻击**:双手各持一把长刀,近战连击。
- **机动**:背部喷气装置,喷气快速突进拉近距离(远距离的压迫手段)。
- **技能**:胸炮——胸甲展开蓄能(可读前摇)后发射;前摇即玩家的惩罚窗口/走位提示。

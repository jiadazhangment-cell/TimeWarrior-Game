## 一、战役总结构:五章 → 13 幕厚战役

**幕公式**(每幕 15-25 分钟,新增成本只集中在"限定新意"一项):
> 1 个环境子皮肤(房间模板库拼装)+ 同 rig 换装/词缀精英兵(零建模)+ **1 个该幕限定新意(新枪/新机关/新怪三选一)** + 1 个中型 BOSS 或压迫段 + 补给终端节点

**三幕敌人语法换代**(RE4 村/堡/岛的核心,数据挖掘证实是三套独立敌人语法,不是换皮):
- **第一语法·机器(1-2 章)**:可断肢、有弱点、巡逻编队——奖励精准点射(现状)。
- **第二语法·生物(3-4 章)**:不可断肢、冲脸、高速低血——**作废爆头肌肉记忆**,逼走位+面杀(生物 ABC 独占一幕段,不与机器人混着首发)。
- **第三语法·融合(4-5 章)**:生物挂机械残骸、军事化机器人开始远程还击(补 Archer 位)——两套语法混编+尸潮融合体登场。

**敌人五分类矩阵**(RE4R 分析框架:Obstacle/Archer/Meatball/Reflex-Tester/Tactical):现有阵容偏 Obstacle/Meatball,**缺 Archer(远程牵制)与 Tactical(战术精英)**——用现有骨架换 AI/词缀补齐,新鲜感靠组合排列不靠堆种类。

**敌人三段式投放纪律**(每个高价值敌人用三次):单独教学(1v1 空间充足)→ 加环境限制 → 混编当压力源。

**一次性机制预算纪律**(入 CLAUDE.md):每关只批一个 setpiece,且最多解决该关战斗量一半,用完即弃(双巨人熔炉拉杆只杀一只的纪律)。

## 二、尸潮融合体(用户点名场景,完整设计)

**蓝本**:TLOU2 鼠王(聚合+分体攻坚,制作访谈:公式抄战神 Magni/Modi 一快一慢)+《Inside》Huddle(2D 横版苍白肉团、零血腥的美术先例)+ RE4 Regenerador(三段式"先杀不死"投放)+ 撤退墙怪 Wallmonger(横版专属的"移动尸墙"变体)。

**为什么是我们的招牌**:尸体 ragdoll 留场+静止烘焙是现成系统,且尸体是真实 Matter 刚体——融合演出不播动画,**对场上每具真实尸体施向心力、物理地拖拽聚拢**(体积/血量/构成由玩家本场实际击杀数决定,每个玩家看到的融合体都不一样)。

**三段式投放**(同一份美术用三次):
1. **第一遇(4.2)**:清完生物房间往前走→身后已烘焙的尸体开始抽动(声音先行:低频蠕动+光点回流)→被无形力量拖拽聚拢成体。**此时杀不死**,一次性机制=环境处决(引到重型压机/闸门下压掉一部分形态)。
2. **第二遇(拿到时相透镜后)**:残部重新组装,透镜下可见内部 N 个青绿核心节点——战斗=打核心;掉血到阈值**分裂出 1-2 只敏捷型 C**(鼠王分体)单独扑击。
3. **完全体(5.2)**:会**主动吞并战场新产生的尸体自我修复**——玩家第一次要为"留不留尸体"负责(击杀位置选择变成战术)。

**红线方案**:无血无断口——聚合用**青绿发光能量束缚**缠绕苍白生物量轮廓(培养舱同色系),吸收表现为"能量光点回流"(把现有死亡消散光点倒放),分裂/受击掉的是光点与生物量团块。

**工程**(新建 Amalgam.js,~200 行,零新系统):选取候选尸体→逐 part 施向心冲量+重分配到统一负碰撞组(防融合体自碰抖动,GibSystem 每尸独立负组是现成机制)→到位重建关节+焊接进复合骨架→移交 Enemy 实例。开工前必读 GibSystem 头注释(位移窗口烘焙/CCD 铁律)。**先立独立原型验证多 ragdoll+能量丝缝合的观感与性能。**

## 三、生化暴君·未来的自己(终 BOSS,战役脊柱)

**结构模型 = RE3 Nemesis**(分幕剧情式登场,每次比上次强),不是 Mr.X(环境常驻那个位置给了 4.1 的机械追猎者,一纵一横两种压迫不打架):

- **2.3 掠影**(3 秒,不接战)→ **3.3 追击①**(未完全变异:装甲还认得出,半边已被生物量包裹;打不死只能逃)→ **4.3 登场②**(新能力:青绿能量藤蔓抓取——藤蔓=光带,规避血肉触手红线)→ **5.3 决战**。
- **身份揭示零台词**:伏笔①序列号浮字 → 伏笔②透镜下的装甲人形轮廓 → 决战前它做一个**玩家的招牌动作**(换枪的抛接手势,InputState 回放驱动同一套 CharacterRig=引擎白送)→ 玩家自己认出来。
- **决战三阶段**:①装甲态(机器语法:可断肢!打掉的每块甲都掉出光带缠绕的生物量=视觉揭示)→ ②暴君态(生物语法:苍白巨躯+青绿束缚,冲脸+藤蔓+吞尸回血,弱点=透镜可见核心)→ ③决着(竞技场环境耦合:时锚钻机平台参与规则)。ProbabityChoose 攻击选择器+双目标变焦相机两件基建先行。
- **结局分支(唯一分支,拍板)**:终结它 / 用时相器最后一次逆转把"未来"改写——二选一双结局,或单结局不做分支。

## 四、RE4 移植系统件(战役骨骼)

1. **隐形 rank 动态难度**(社区完整逆向数值表可直接抄):Rank.js 标量 1000-10999,爆头+127/击杀+75/受伤-400/死亡-800,非对称阻尼;输出→敌人前摇/掉落频率/rank 门控敌人(minRank 字段)。**比"选难度"更适合 4399(玩家不用承认自己菜)**;保留一个锁死最高档给硬核。天然回应"难度=头号劝退"。
2. **补给终端仪式**(商人=节奏标点的移植):固定视觉母题的安全房(蓝光/无敌人/换枪/看战报/射击场靶位),检查点显性化;战斗起止用音乐信号不用文字;章末字幕卡+自动存档+战报=固定三件套(4399"多局党"的自然离场点设计在爽点上)。
3. **数据五分离**(RE4 .ESL/.AEV 架构):geometry/enemies/items/events/patrol 各自独立 json——**重玩层几乎白送**(同几何+换 enemies.json=噩梦难度;换 events.json=佣兵模式)。刷怪纪律精确化:常规=预置+触发区激活;仅围攻/佣兵/封锁语境允许生成,且必须从画面内可见的门/管道口进入。
4. **词缀精英系统**:机器人(过载自爆/护盾反弹/狂暴冲锋)、生物(分裂产卵/群体唤醒/磁场干扰)各 2-3 词缀,同骨架+改数值+换特效色;词缀必须带可感知的行为差异,否则=换皮注水。
5. **支线委托**:隐藏收集包装成委托("打掉 B3 三个监控探头"),目标一律远处可见一枪可击(蓝徽章原则),不做敲箱子杂活。
6. **武器携带槽位(单独拍板)**:5 枪只能带 2-3 把,补给终端换装——弹药无限下的"空间张力"替代品,每到终端做一次自我评估。**改变现有 1-5 全携体验,需要你点头才做。**

## 五、重玩层(成本从低到高)

图鉴(零成本顺手)→ 挑战清单(跨周目累计,纯事件统计)→ **Boss Rush**(零成本,4399 优先级最高)→ 噩梦难度(rank 锁死+换 enemies.json)→ 计时评价(S+ 式:限时+存档次数双约束)→ **佣兵模式**(蜂巢层限时连杀+连击计分+排行,注意计分模式 rank 要反接:打得好→更多敌人=更多分)。多结局只留终章那一个分支。

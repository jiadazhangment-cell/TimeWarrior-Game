## 设计定论(已由主控与用户对齐,照做)

**病根**:玩家沿 X 轴穿过风道,叶盘物理上在 YZ 平面(垂直于行进方向),侧视相机(沿 Z 看)理应看到叶盘的**侧剖面**——现在却画成正对屏幕的圆盘+同心圆护罩,"所见"与"所碰"两个世界,且冷蓝灰配色在暖金大厅里是异物。

**新结构(剖切语言,与本项目"暗门地下结构剖面件"同语法)**:
1. **风道=水平圆筒的剖切**:墙面上下两段实体(碰撞条目 fanwall 已存在,几何勿动:洞口竖直范围 cy±r = 400±230 → 170..630),洞内=看得进去的风道内腔(向远处收暗的水平走向,横向板缝拉出进深)。
2. **电机舱**:洞心 y=cy 处一枚**水平胶囊形整流罩**(顺 X 轴,长约 130、半高约 46),鼻锥+散热环+定子支撑杆(上下各一根竖撑连到洞壁,静态)。轴沿 X,这才是轴流风机侧看的样子。
3. **叶片=扫过洞口的斜削板条**。数学:叶片绕 X 轴转,相位 φ_k = angle + k·2π/3(**叶片数改 3**,大直径工业轴流常态,也是停机可通行的关键);侧视投影:
   - 板条竖直跨度:从电机舱边缘伸向 y_tip = cy − r·cos(φ),即 |cosφ| 控制投影长度(指向相机时缩为零=正常,别修)。
   - **近侧/远侧**:sin(φ) > 0 = 近侧(画亮、参与判定),sin(φ) < 0 = 远侧(画暗、纯背景、不判定——偏袒玩家红线:看不清的不打你)。
   - 板条形状:根窄梢宽微扭(保留现叶形语言),屏幕内宽度=弦宽 ~30px 常数(风道板厚方向),沿跨度方向微斜切;近侧亮 3 档+前缘受光棱,远侧压暗至洞腔色+轻模糊感(多画一层低 alpha 残影即可)。
   - 运动:近侧板条随 φ 扫过洞口(上→下或下→上取决 cos 变化),配速度残影(沿 Y 拖影,数量随 speed,复用现 ghosts 思路但改竖向)。
4. **停机停位对齐改"Y 形位"**:_alignTarget 改为最近的 `k·2π/3`(blade0 指正上)。停位后投影:一片全长朝上板条+近侧一片斜停板条(梢端 y = cy + r·0.5 = 515)+远侧一片暗板条。**洞底通行带 515..630 = 115px 净空,站立(92)头顶 538 有 23px 余量**——"停机后走得过"从视觉上成立。判定层 running=false 本就免伤,勿改。
5. **命中判定改投影重叠**(替换现在的径向扇区):玩家在墙厚平面附近(保留现 |p.x−cxm| ≤ wallW/2+24 门)且存在近侧叶片(sinφ > 0.15)其投影段 [min(cy, y_tip), max(cy, y_tip)](含速度前瞻扩张,沿用 `+speed*0.03` 换算到 Y 方向:扩张量 = r·speed·0.03)与玩家胶囊 Y 区间重叠 → 命中。伤害/击退/trauma 语义全部照旧(hurt(touchDamage)、甩回 vx=±340、vy≤−170、addTrauma 0.35)。**slow 档掐隙窗口必须仍然存在**(3 叶 @0.5rad/s 近侧下半扫掠周期性留空,自查推演写进报告)。
6. **吸力/排风逻辑一个字不改**(位移注入是拍板过的定版手感)。但**补吸力可视化**:running 且 k>0.3 时,吸入侧画 4-6 条向洞口汇聚的低 alpha 气流细线(长 60-120,沿吸力方向流动,随 k 增强;排风侧反向、更淡)。线条要有生命周期流动感(相位滚动),不是静态贴纸。
7. **配色入暖**:整套从冷蓝灰(0x10141a/0x171d24/0x39424f/0x49515b)迁到暖工业调,与大厅金褐咬合:墙板基 0x181410/0x221b13,板缝近黑暖 0x0d0a07,金属件 0x4f463a/0x5c5244,叶片亮面 0x6b5f4e+受光棱 0x8a7c66,洞腔向 0x050403 收暗,洞口近沿留一道暖金环境反光(0x8a6a3a alpha 0.25 窄弧,只在朝大厅一侧)。黄黑警示带保留(0xd8b13a 已是暖黄)。状态灯语义勿改(运转红/慢转闪/停死暗绿)。
8. **删除正对屏幕专属元素**:同心圆+辐条护罩(坐标纸感的来源)、井口螺栓一圈、圆洞同心环纵深——全部换成上述剖切语言。洞底以下墙基那块黑矩形按墙板语言补画(板缝+踢脚+黄黑斜纹)。

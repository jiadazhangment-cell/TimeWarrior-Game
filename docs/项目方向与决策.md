# 项目方向与决策

> 本文件是项目的"宪法附录":记录游戏是什么、拍板过什么、还悬着什么。改动大方向前先看这里。

## 一、游戏概述
- **类型**:2D 横版通关射击(H5),科幻题材。
- **故事**:一名时空战士潜入外星基地,逐章消灭敌人。
- **规模**:5 个章节,每章独立场景与敌人构成;章节内穿插考验操作灵活性的机关/动作环节(非纯战斗)。
- **武器**:4 种,伤害递增——步枪 → 霰弹枪 → RPG → 手持超级大炮。细节开工后细化。
- **发布**:4399 开放平台(个人开发者);变现 = 活动奖金 + 激励广告(需商务开通)。
- **卖点**:物理演出(击飞/断肢/惯性)+ 流畅 60fps + 清晰矢量画面,与老式"机械感"2D 游戏拉开差距。

## 二点五、设计后备清单(用户已提出,待排期实现)

- **AI 难度分级**(用户 2026-07-13 提出):简单模式=人机不蹲掩体、不躲子弹;困难模式=会下蹲躲掩体、有意识躲子弹。实现建议:enemies.json 按难度挂 aiProfile(useCover/dodgeAwareness 等开关),M3 做难度系统时落地。
- **美术精细化 pass**(标杆=docs/风格参考/参考7-精细度标杆.png):板甲分件细节、面板线、双色阶阴影、装备挂件(背包/红十字/能量灯)、精细枪模(导轨/弹匣/握把分明)、开枪等特效精修。路径:SVG 部件做"细节强化版 v2"(参考图完全可用矢量复刻:平涂+阴影带+线细节),必要时结合同风格素材参考与 AI 生成的概念参考。排期:M2 开头做玩家+机器人 v2,后续每类新敌人按此标准。
- **室内场景丰富化**:基地=室内感——灯具与光效(顶灯光晕/应急红灯/设备指示灯)、外星设施道具(培养舱/管线/舱门/全息屏)、地图巧妙复杂(多路径/垂直结构/机关联动)。排期:M2 第一章关卡设计按此标准起步。

5. **"测试通过≠好玩"**:手感类改动必须用户试玩。

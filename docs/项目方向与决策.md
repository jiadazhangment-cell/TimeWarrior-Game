# 项目方向与决策

> 本文件是项目的"宪法附录":记录游戏是什么、拍板过什么、还悬着什么。改动大方向前先看这里。

## 一、游戏概述
- **类型**:2D 横版通关射击(H5),科幻题材。
- **故事**:一名时空战士潜入外星基地,逐章消灭敌人。
- **规模**:5 个章节,每章独立场景与敌人构成;章节内穿插考验操作灵活性的机关/动作环节(非纯战斗)。
- **武器**:4 种,伤害递增——步枪 → 霰弹枪 → RPG → 手持超级大炮。**已全量落地(2026-07-25)**:切枪(1-4/Q/滚轮+按枪硬直)/分类型弹道(hitscan/7弹丸霰弹/抛物线火箭+分层爆炸/穿透大炮)/armgun 换整图美术;参数以 docs/入侵者2武器体系设计表.md 为锚;试玩态全解锁,正式流程拾取解锁(WeaponSystem.unlock 入口已留,关卡节点归内容线);弹药模型未上(设计表有方案,待拍板)。
- **发布**:4399 开放平台(个人开发者);变现 = 活动奖金 + 激励广告(需商务开通)。
- **卖点**:物理演出(击飞/断肢/惯性)+ 流畅 60fps + 清晰矢量画面,与老式"机械感"2D 游戏拉开差距。

## 二点六、R1-R6 质量改造路线(2026-07-16 拍板,M2 内执行,每批次用户试玩拍板后进下一批)

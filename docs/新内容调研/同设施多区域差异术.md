# 同设施多区域差异术(调研)

> 日期:2026-07-27 · 用途:第 2-5 章"不出基地"的多区域推进(后段动力/制造类工业区 + 出口大混战)。
> 命题:每进一区要有"到新地方了"的强烈感受,整座设施又必须读作"同一个地方"。本文只给方法与案例,不含拍板。

## 0. 一句话结论

**区域差异 =(变量层大改)+(不变量层零改)+(阈限仪式)**。三者缺一:
只改变量 → 像换皮包;只守不变量 → 像注水;没有阈限 → 玩家压根没意识到自己换区了。

成本序:**先买"明度/饱和分离 + 剪影语言 + 敌人构成 + 音景",最后才买"全新素材库"**。
硬证据:Dead Cells 全部生物群系共用同一套凯尔特建筑 + 炼金视觉语法(铜/玻璃/符文),区域配色靠
**"灰度画背景 + 渐变映射(gradient map)"**——改一张渐变图 = 换掉一个区的整套配色,零重绘;
Promenade 原本橘色与相邻关卡打架,直接调渐变图改成蓝调收工。另配每区独立变量:光照色与强度、
烟/雾/水/植被密度、粒子量。而"玩法件"(旗帜、石环底纹、可交互物亮度)全区严格同一套语言,不许变
(来源:gamedeveloper.com《Art Design Deep Dive: Giving back colors to cryptic worlds in Dead Cells》)。

## 1. 骨架:三层预算表(每开一个新区,先填这张表)

| 层 | 具体项 | 纪律 |
|---|---|---|
| **不变量(锚)** | 走道带高度与地板线、闸门/舱门形制、警示灯三段式语言、标牌与管线色标系统、HUD、玩家动作语法、掩体尺寸规范(52/84/38/22) | **全区零改**。这是"同一设施"的全部凭证 |
| **变量(杠杆)** | ①主色相 ②明度/饱和度 ③背景剪影(什么形状占天际线) ④装饰密度 ⑤雾/尘/蒸汽 ⑥光源类型与色温 ⑦敌人构成 ⑧地形语法(垂直度/掩体密度/危险源) ⑨音景 | **每区至少换 3 项**,且必须包含 ②或③ |
| **阈限(仪式)** | 上一区末端的"预告边缘" → 过渡空间(气闸/电梯/桥/风管) → 新区第一屏定场 | **每次换区必做全三拍** |

> 为什么②(明度)不能省:2D 横版玩家的视野只有一屏,色相差可以被"压暗保可读性"的 tint 吃掉,
> 但明度差吃不掉。§6 有本项目现有四层 tint 的实测,正好踩了这个坑。

## 2. 案例 A:横版动作射击——一关之内怎么换区

- **Metal Slug 系列**:换区靠"推进方向 + 载具 + 层级"三件套。惯用序列是`地表横推 → 上载具/夺车 →
  破门或下潜进入敌方基地内部 → 纵向井道/电梯 → 锁屏 BOSS 舱`。MS3 第 3、5 关即敌方军事基地内部关。
  关卡设计师九条一马(Kazuma Kujo)被评价为"比其他设计师更流畅",做法之一是**尽量少用把玩家困死在
  一小块的强制卷屏段**(来源:jiemian.com/article/3444462;zh.moegirl.org.cn《军事基地》条目)。
  技术侧:背景不是纯 tile 而是分块大图流式加载——"整关一张纹理太吃内存,纯 tile 又出不来细节",
  与我们"整面概念图平铺"是同一取舍(来源:gamedev.net topic-283950)。
- **Nazca 原班访谈**:被问关卡设计时只强调"确保玩家角色与敌人**易于辨识**"——这是"背景可以随便换,
  但前景对比度不能动"的最早期表述(来源:shmuplations.com/metalslug)。落到我们身上就是
  tint 压暗保角色可读性这条不能因为"换区要好看"而放松。
- **Contra 系列 / Blazing Chrome / Huntdown**:同一关内的换区几乎全部由**一次强制的"穿过某物"**触发
  ——炸开墙、坐降梯、跳上运输车、进管道。玩家的手在那 2 秒是"没事做"的,这正是换素材、换 BGM、
  换环境音的窗口。
- **术语纠错**:用户提到的"钢铁咆哮"=《钢铁的咆哮》(SystemSoft,二战舰船改装战略),**不是横版射击**
  (来源:baike.baidu.com《钢铁的咆哮3》)。同位替代参考建议用 Contra: Hard Corps / Blazing Chrome /
  Huntdown(近未来工业城区分区做得最狠的现代同类)。
- **廉价变异法(通用)**:同一套 tile/道具重排 + 换调色 + 加"损毁与失序"程度差,就能读作另一个地方;
  props 叠在 tileset 之上打断轮廓线是最省的手段(来源:aran.ink/posts/celeste-tilesets;
  80.lv《Using Tileable Textures in Game Environments》)。

## 3. 案例 B:银河城的区域差异语法

- **Metroid Fusion(BSL 研究站)= 与我们同题的最强先例**。一座空间站切成 6 个编号扇区(SRX/TRO/PYR/
  AQA/NOC/ARC),每个扇区**用"生态模拟舱"这个设定为差异发了通行证**:扇区内部是复刻 SR388/Zebes 的
  生境穹顶,所以站内可以同时有丛林、火山、水域、冰区而不违和;**丛林与 BSL 机械背景直接对冲的观感是
  刻意的**。所有扇区挂在同一个中央 Main Deck 枢纽上,靠统一的升降舱进出——差异全在扇区内,"同一座站"
  全靠枢纽与舱门形制来锚(来源:metroidwiki.org《Biologic Space Labs Research Station》;
  goombastomp.com Metroid Fusion retrospective)。
  **这条可以直接抄成我们的世界观**:实验基地本就有"不同研究/生产分区各自定制环境"的现实依据。
- **空洞骑士**:每区一主题色且地图 UI 也守这套色(泪水之城蓝 / 真菌之地与感染十字路橙黄 / 深渊大片灰)。
  关键的一条是**边界预告**:"区域链接处会有下一区域的特色出现的视觉过渡"——进翠绿之径前先看见几点绿。
  工作流是先用**纯黑瓦片房间**搭几何,美术后进场(来源:cnblogs.com/shaoSaxon/p/18120063;
  gameres.com/884998;gwb.tencent.com/community/detail/125859)。
- **区域内敌人也是识别符**:水晶山峰的粉色矿石长进了敌人造型与技能里;变体设计原则是"**一个明确的差异**"
  (最有效的是攻击节奏/时机的差异),不是换贴图(来源:jasondeheras.com《Enemy Design Layers in Hollow Knight》)。
- **Blasphemous**:存档点(Prie Dieu)**大致每区一个、间隔从不超过约 7 屏**——这是目前能查到的最硬的
  "安全区密度"数字(来源:gamedeveloper.com《How Blasphemous' level design iterates on classic Metroidvanias》)。
- **Axiom Verge**:每种环境是一套 16×16 tile,**tile 的"可被干扰性"必须一眼看得出**——区域视觉设计
  同时承担机制播报(来源:gameinformer / retrorgb 的 Tom Happ 访谈)。
- **色彩脚本(color script)**:动画电影的做法,预制作期由美术总监按叙事弧给**每个区/幕一张"色板帧"**
  (主色调 3-5 个 + 冷暖 + 饱和度档位),先定全局序列再落到单个资产。游戏因为非线性更需要它
  (来源:nastyrodent.com《Color Theory for Game Art: The Production Application Guide》)。

## 4. 案例 C:功能叙事——把真实设施的分区逻辑变成关卡主题

- **黑山基地(Half-Life)**:章节序列本身就是一条"设施功能链":办公区 → 异常材料实验室/测试舱 →
  维修隧道 → Blast Pit → 供电区 → 轨道运输(On A Rail)→ 地表 → Lambda 核心 → Xen。开场那趟
  **有轨电车是一次纯粹的"定场镜头"**,把整座设施的规模和分区一次性交代完。
  **通风管道是它换环境最便宜的手法**:钻进去再出来,场景可以彻底不同,还省掉设计"两个区怎么物理相接"
  (来源:half-life.fandom.com《Black Mesa Research Facility》;giantbomb 论坛 Source Material 长文)。
  已知的批评是它的建筑学在现实里说不通(thenocturnalrambler.blogspot.com《Horrible Architecture/
  Engineering in Half-Life》)——**结论正是我们要的:可信度来自"功能标签 + 一致的施工语言",不来自真实图纸。**
- **可选的功能分区菜单**(每行=一个区域主题的成品配方):

| 功能区 | 主几何 | 标志剪影 | 光 | 危险源 | 音景 |
|---|---|---|---|---|---|
| 动力/发电 | 巨型竖直筒体、汇流排 | 涡轮机壳、母线塔 | 高对比,弧光蓝白闪 | 电弧、蒸汽、过热 | 低频嗡鸣 + 周期性泄压 |
| 制造/装配 | 长向水平输送线 | 机械臂列、吊装轨 | 均匀顶棚工作灯,偏冷白 | 冲压/传送带/焊枪 | 节拍性金属撞击 |
| 仓储/物流 | 高货架峡谷、装卸台 | 堆垛、集装箱、叉车 | 稀疏点光,大片暗区 | 坠物、狭窄视线 | 空旷混响 + 远处滚轮 |
| 控制/机房 | 密集小房间 + 玻璃幕 | 机柜阵、屏幕墙 | 屏幕自发光为主 | 封闭、无掩体 | 风扇白噪 + 提示音 |
| 冷却/水处理 | 大池体、管廊 | 阀组、冷却塔内壁 | 水面反光、雾重 | 淹没、滑动、低温 | 水声 + 泵 |
| 废料/化学储存 | 罐体林、围堰 | 立式储罐、泄压管 | 昏黄、警戒橙 | 可燃/腐蚀(接现有气瓶) | 滴漏 + 通风 |
| 管廊/夹层 | 极窄横向 | 管束、桥架、爬梯 | 应急灯条 | 无掩体的长直线 | 密闭近场 |

- **每区一主色可以是"设定内合法"的**:ANSI/ASME A13.1 管道标识色标——**黄底黑字=易燃/助燃液气**、
  **绿底白字=饮用/冷却/锅炉给水**、**蓝底白字=压缩空气**、**红底白字=消防介质**(另有橙=有毒腐蚀、
  棕=可燃液体);标签沿管每 25-50 英尺重复一次(来源:creativesafetysupply.com/articles/pipe-colorcodes)。
  → 动力区黄、冷却区绿、气动/制造区蓝、消防/出口红,**不是美术任性,是照着真标准刷的**,
  而且"管线色标"这条我们的 docs/室内设计元素库.md 第 10 条已经收录过,可以直接升格成全局分区色系统。
- **RE 洋馆/RPD 的分区记忆点**:靠**一个中央地标(主厅)+ 东西两翼 + 钥匙卡分级**,让玩家用房间名
  ("图书室""温室")而不是坐标记路;现代版还加了大量环形路线与抄近道(来源:en.wikipedia.org
  《Raccoon Police Station》;resetera RE2R 关卡设计长帖)。→ 横版化就是:**一个贯层枢纽 + 左右两翼 +
  逐级权限门**,我们的电梯井其实已经是这个枢纽的雏形。

## 5. 过渡与节奏

- **强度曲线**:交替高低,不要长时间维持高压("玩家会适应持续高强度");开场压低、Boss 后给低强度段当
  "清味剂";**终局不该是最难的一战,而应读作高潮的必然结果**。HL2:EP2 的强度图把节拍分为
  Explore / Combat / Choreography / Puzzle 四类,其中 Choreography(编排段)专门用来**标记战斗边界**
  (来源:book.leveldesignbook.com/process/preproduction/pacing)。
- **过渡空间的四个职能**(电梯/气闸/长廊/风管/桥):①张力清零 ②资源加载 ③**预告下一区**
  ④给玩家反刍时间。加上一个战斗设计用法:**用单向入口(短坠落或身后关闭的气闸门)把玩家推进竞技场**
  (来源:同上 + book.leveldesignbook.com/process/combat/encounter)。
- **定场与远景(vista)**:望向"可玩区"的远景 = 让玩家看见路线与目标(赋权);望向"不可玩区"的远景 =
  纯奇观时刻,专门用在 downtime。手法上"窄通道突然开阔 = 抵达感","门框框住景 / 半墙露一角 = 好奇心"
  (来源:code.tutsplus.com《Level Design: Views and Vistas》;architizer《An Architect's Guide To Level Thresholds》)。
- **安全区**:密度参考 Blasphemous 的"每区约一个、不超过 7 屏"。RE 式做法是给安全区**专属的音乐/环境音**,
  让"安全"变成一个听觉状态而不是一个 UI 图标。
- **回头路不注水**的四种变量(按成本从低到高):①旧房间换新敌人/精英词缀 ②开单向近道使二次通行更快
  ③**环境状态改写**(断电/进水/起火/封锁/被生物量侵占)④新能力使旧地形读法改变。
  Metroid Fusion 的经典手法就是**强制回头时把区域"变异"成另一副样子**;反面共识是"没有新变量的二次通行
  就是偷懒"(来源:nintendojo.com《The Backtracking Metroidvania Paradox》;resetera 相关长帖)。
  → 我们提案 §5.1"重访第一章废墟态"已经踩在③+①上,方向正确,注意别只做①。
- **音景切换**:每区一条循环底噪 + 一组按位置/概率触发的点缀音;换区时**交叉淡化底噪并换掉整组点缀音**
  是行业标准做法;分层写法=前景(脚步)/中景(风、机械嗡)/背景(远处低鸣)
  (来源:gamedeveloper.com《Creating an Interactive Audio Environment》;gameaudiolearning.com)。

## 6. 落地到我们现有管线

- **建"区域档案表"(Region Profile),而不是零散改参数**。我们其实已经有雏形:
  `src/scenes/ArenaScene.js:476-479` 的四层数组 `{ tex, walkR, tint }`。建议扩成一行 9 字段:
  `{ tex, walkR, tint, fogAlpha, dustDensity, lampColor, ambientKey, enemyMix, decorSet }`,
  新区 = 加一行 + 一张概念图,而不是加一堆散落的 if。
- **实测:现有四层 tint 的差异只用了三分之一个维度**(2026-07-27 量):
  | 层 | tint | 色相 H | 饱和 S | 明度 V |
  |---|---|---|---|---|
  | B1 行政 | 0x9aa2ae | 216° | 11.5% | 68% |
  | B2 低温实验 | 0x8aa0a8 | 196° | 17.9% | 66% |
  | B3 安防 | 0x9a94a6 | 260° | 10.8% | 65% |
  | B4 机房 | 0xa89390 | 7.5° | 14.3% | 66% |
  色相拉开了(196/216/260/7.5),但**四层的明度全挤在 65-68%、饱和度全挤在 11-18%**。
  人眼对明度差最敏感,四层一样亮 = 换区感被吃掉一大半,差异实际全靠墙面贴图在扛。
  → 新区至少把 V 拉到 50%-80% 的跨度(仓储/废料压暗,动力/制造提亮),并让**至少一个区的 S 破 25%**
  当"色彩事件"(参考 Dead Cells 用高饱和维持统一、用亮度与对比播报危险)。
- **概念图出图 prompt 里写"区域档案"**:现行配方(侧视正交 + 场景内容清单 + 无人物无文字)之上,
  每区**追加三句**:①主色与光源类型(如"主色警戒黄,光源=顶部钠灯 + 弧光闪")②天际线剪影清单
  (如"画面上三分之一被涡轮机壳与母线塔占据")③损毁/失序程度。**走道面仍锁在画面下三分之一**
  (与走廊图同构,保证地板线可拼接)——这条属于§1 的不变量,永远不许因为"换风格"而动。
- **decor 家具层 = 差异的第二引擎**。已有 B1/B2/B3/B4 四套专属家具(参考25/26/28/29)证明这条路通。
  新区不必等整面墙图,可以**先用"同一批结构件 + 新家具集 + 新 tint"过渡**,墙面图后补。
- **背景动效层按区换元件**:`_decorateBackdrop` 已按源图像素坐标定位。动力区=弧光闪 + 母线辉光呼吸;
  制造区=输送带纹理横向 tileSprite 滚动 + 机械臂周期摆;仓储区=尘埃缓降 + 远处叉车灯扫;
  控制区=屏幕墙 CRT 扫描线(现成)。**别新写系统,全是现有 px_glow / px_scanline / tileSprite 的重组。**
- **敌人构成同步换**:按提案 §一的三语法换代,把"哪几种敌人只在哪个区出现"写进区域档案表的 `enemyMix`。
  最省成本的区域标记 = 同 rig 换装 + **改一个明确差异**(优先改攻击节奏,不是改贴图)。
- **阈限的三拍在我们这儿的现成件**:预告边缘 = 上一区末端塞两件下一区的家具/色标管线;
  过渡空间 = 现成电梯厢(参考21)与闸门(参考17);第一屏定场 = 进区后给一段无敌人的横推 +
  一次镜头小幅拉远(R3 动态变焦已有,注意屏幕件逆补偿那条坑)。

## 7. 后段区域菜单(按"差异强度 × 成本"排序,供拍板取用)

| 候选区 | 与蜂巢的对比点 | 新增美术成本 | 玩法钩子 |
|---|---|---|---|
| **管廊/夹层**(过渡区) | 极窄横向、无掩体 | 极低(全用现有结构件) | 长直线火力压制、无处可躲 |
| **仓储/装卸区** | 暗、竖向货架峡谷 | 低(货箱=现成掩体逻辑) | 堆垛立体机动、坠物、视线遮断 |
| **动力/发电区** | 最亮、最高对比、弧光蓝白 | 中(1 面墙图 + 涡轮件) | 断电/供电开关改写全图状态 |
| **制造/装配线** | 水平节拍、有运动地形 | 中(输送带 + 机械臂) | 移动地形、冲压节奏、可夹死敌人 |
| **废料/化学储罐** | 昏黄警戒橙、可燃 | 中(罐体林,接现有气瓶爆炸) | 连锁殉爆,FluidFx 主场 |
| **出口大混战** | 见天光、最大开阔度 | 高(需要"外面"的第一眼) | 无限增援 + 明确撤离目标 |

> 出口区建议单独立规:它是全作唯一一次"色温从人造光转向自然光"的机会,**把这张牌留到最后一屏**
> (色彩脚本的收尾)。在此之前所有区域都应保持"人造光源"这条不变量。

## 8. 反面清单(容易犯的)

1. 只换 tint 不换剪影 → 玩家读作"同一张图调了个色"。
2. 每区都新画整套素材 → 成本爆炸且风格漂移;正确解是**不变量库 + 变量层**。
3. 换区没有阈限段 → 走着走着背景变了,读作 bug 或美术接缝。
4. 四个区四种明度一样 → 见 §6 实测。
5. 过渡空间做成"长且什么都没有" → 过渡段必须带一个职能(预告/奇观/补给/剧情),否则就是走路。
6. 回头路只换敌人不换状态 → 注水感的主要来源。
7. 一次给玩家两个新变量(新区 + 新机制同屏首发)→ 违反提案已定的"三段式投放"与"每关一个 setpiece"。

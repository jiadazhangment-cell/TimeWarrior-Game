# 巨物机关与"震撼感"设计语法

> 调研日期 2026-07-27 | 方法:web 检索(GDC/CEDEC 讲稿、gamedeveloper.com、TV Tropes、各游戏 wiki/StrategyWiki、关卡设计师复盘、声学论文)
> 用途:**用户点名方向** ——"我希望做一些比较大的东西,那样感觉比较震撼一点。比如可以做一个巨大的正在转动的风扇,必须使它停下来,不然转不过去。还有其他一些巨大的设施。"
> 本文只给**可直接落地的机制与表现规则**,每条带一句"▸落地"对齐我们现有系统。不含实现代码。

---

## 0. 总纲 + 本项目基准数

**一句话:巨物的震撼不是"把贴图放大",是四件事同时成立 —— ①它比屏幕大(看不全) ②它动得慢但停得住 ③它有低频声床 ④玩家能改变它的状态。** 缺第④条就只是背景板。

我们的既有基准(写方案时按这套算,别凭感觉):

| 项 | 值 | 出处 |
|---|---|---|
| 画布 | **960 × 540** | `config/game.json` |
| 玩家碰撞 | **30 × 88 px**(≈ 屏高的 1/6) | `config/player.json` |
| 重力 | 1900 px/s² | `config/game.json` |
| 镜头变焦 | calm 1.07 / combat 0.97(**已有动态变焦**,拉远是现成手牌) | `game.json.camera` |
| 碰撞总原则 | 一切实体 = `scene.solids` 条目 + Matter 静态体;**动态增删已验证**(开门 = solids 移除 + 删 body,玩家/敌人/子弹/激光/视线零改动自动跟随) | `src/systems/Devices.js` 头注释 |
| 运动学实体 | 电梯已跑通"solid 条目随帧移动 + **先带乘客后挪厢**" | `src/systems/Elevator.js` |
| 可击破 | breakables 有 hp,打爆后瘫痪联动装置,**残骸保留碰撞当掩体** | `Devices.hitBreakable` |
| 震屏 | 全项目只有 `cameras.main.shake(dur, v)` 一处 —— **有升级空间**(见 §3.6) | `ArenaScene.js:368` |

**尺度换算表(照抄即可):**"巨物"至少要 **≥ 3 屏高等价物的视觉体量**。风扇直径 **540~800 px**(整屏高~1.5 屏高,玩家只到它一片叶子的宽度) = 单屏内看不全,必须靠镜头拉远或走位才拼得出全貌。这是下面所有构图规则的前提。

### 1.2 从案例里抽出的六条硬规则

**① 同一台风扇必须有两态以上,而且第二态是"工具"不是"更危险"。**
Blast Pit 是本条的教科书:开着的风扇既是刀也是电梯。二段使用还有一层 —— 风扇开着时往井缝丢手雷,手雷被风吹上去炸掉顶层挡路的木板(玩家自己发现的解法)。
▸**落地**:我们的风扇不要只做"停下才能过"。做成"停 = 能走过去;转 = 上升气流能把玩家/尸体/手雷托上高层平台"。二周目回头刷高处补给必须重新开风扇 —— 这就是用户要的"重新启动"二段使用。

**② 停机方式要有材质分级,不能是"扔任何东西都行"。**
HL2 玩家实录:木板会被叶片打碎、有些物件直接穿过去、**铁锹/水泥砖/油漆桶(金属/重物)才卡得住**。这条分级把"随便扔"变成了"找对东西"。
▸**落地**:复用 `Devices.breakables` 的 hp 概念反过来用 —— 给可投掷物打 `hardness` 标签,软件(木箱)进叶片 = 碎屑特效 + 风扇不受影响;硬件(钢梁/配电柜残骸)进叶片 = 卡停。**我们已有"残骸保留碰撞"**,正好让打爆的配电柜残骸变成合法卡停物。

**③ 断电优先于卡停 —— 用可击破配电柜,这是我们成本最低的一条。**
Metroid Prime 3 的"打爆两侧节点 → 过载"和 Darktide 的"集电池 → 供电 → 按钮"是同一个骨架:风扇本身打不动,**外围的供能物打得动**。
▸**落地**:`Devices.hitBreakable` 已经支持"打爆配电柜 → 瘫痪联动激光栅栏"(`L.def.cabinet === id`)。把 `cabinet` 这条联动直接接到风扇上即可,几乎零新代码。可以要求**打爆 2~3 个**分散在不同高度的柜子,把机关摊成一段跑图。

**④ 教学时刻必须脚本化,不能靠玩家自己送死。**
《Turbine Ruins》开场脚本:两个敌人冲进风扇门当场被绞死。玩家零成本学会"这东西碰不得"。同一关还有:风扇连着**拉杆 + 红绿指示灯 + 电线**,视觉连线把因果画出来;拉杆抬高放在电箱上更醒目;铁板故意放在风扇旁,玩家第一次捡起来就自然掉进缝里卡停 —— 免教学。
▸**落地**:风扇入场时脚本一个敌人被吸进去(复用 `GibSystem` + `FluidFx` 血雾)。风扇↔配电柜之间画**发光电缆**(`scene-fx-pipeline` 的动效层),柜子亮红灯 = 风扇通电,打爆变灰 = 停机。这一条比任何 UI 提示都管用。

**⑤ 惩罚要分级,不要一律秒杀。**
秒杀(HL/HL2/TR)适合"这是禁区"的语气;Fall Guys 的"只是摔倒"和 Crash 的"死一条命"适合高频通过的关卡段。我们是射击游戏不是解谜游戏,**秒杀会打断战斗节奏**。
▸**落地**:建议**碰到叶片 = 高额伤害 + 强击退**(把玩家甩回上一个平台),而不是即死。真要即死就配一个近距离检查点(`SaveStore` 已有 checkpoint)。

**⑥ "不完全停"比"完全停"更好玩。**
TotK 是卡到**减速**,Crash 是**不停机从缝穿**,Gauntlet 是**减速开关**。完全静止的风扇视觉上死掉了,巨物感立刻消失。
▸**落地**:强烈建议做三档 —— 全速(秒过不去) / **卡停后仍在缓慢抖动挣扎(轴承嘎吱声 + 每隔几秒猛地跳半格)** / 彻底断电停死。中间那档最有戏:玩家从缝里过的时候心里在打鼓。

**⑦ 一条实现坑(别人踩过的)。**《Turbine Ruins》作者的复盘:把大涡轮做成可站立的桥时,物理刚体 `func_physbox` **不稳定,玩家站着不动会掉下去**;最后改成"用不可见碰撞体复刻涡轮停位时的形状,固定摆在那儿",转动时玩家被碰撞体弹开、停机后才能站上去。
▸**落地**:直接抄。我们的风扇叶片**不要做旋转 Matter 刚体**。转动 = 纯贴图旋转 + 一个"扇面伤害区"传感器;停机 = 往 `solids` 里**插入几条静态条目**(刚好对上停位那几片叶子的位置),叶片瞬间变成可站的平台。这跟 `Devices` 开关门是同一套动态增删,已验证。

## 2. 其他巨大工业设施机关:案例库

每条 = 案例 + 一句机制 + 落地。

| 机关 | 最佳案例 | 机制一句话 | ▸我们怎么落地 |
|---|---|---|---|
| **冲压机阵列(时序穿越)** | DKC Returns《Slammin' Steel》 | 一整排压机砸地;其中一台**和整屏一样长,跑不过去** —— 必须躲进压机本身的凹槽里,**压机的形状就是避难所** | 压机 = 运动学 solid 条目(与电梯同一套"先带乘客后挪"),下压时压到玩家 = 大伤害+击退;凹槽用贴图切件对齐碰撞条目 |
| **绞肉机(变速而非开关)** | Oddworld: Abe's Oddysee | 拉杆控制的是**转速档(慢/快/反转)**不是开关;**一个拉杆同时改两台**(一台变慢另一台必变快)= 资源互斥;还能把敌人骗到落桶下砸死 | 最值得抄的一条:做"总配电只够供一台"的互斥拉杆,玩家必须选择让哪台停 —— 一根拉杆造出两难 |
| **巨型齿轮(反转+停顿窗口)** | Limbo ch.28 / 30 | 拉杆**反转旋向**,反转的瞬间有个**停顿窗口**,就在那一下跳上去;齿轮还能**载着你走**;把箱子放齿轮上运货 | 齿轮 = 贴图旋转 + 圆周上挂 N 个运动学 solid 小平台;"反转停顿"= 角速度过零点时给 400ms 的可站窗口 |
| **齿轮把房间转起来** | Limbo ch.28 | 把小齿轮推进大齿轮 → **整个房间开始旋转**,重力相对方向变了 | 成本高,不建议做整房旋转;可退化为"倾斜的走廊 + 缓慢下滑" |
| **传送带(站上被推/逆行)** | Hollow Knight 水晶山峰;DKC Returns;Mega Man X 工厂 | 站上去被恒定推移;逆行 = 移动速度净损耗;传送带 + 头顶压机 = 复合威胁 | 传送带 = 普通 solid + 一个"接触时给水平速度偏置"的标记(玩家/敌人/**尸体**都吃这个偏置 —— 尸体被传走的画面就是巨物感) |
| **熔炉/浇铸(定时热流)** | Mega Man X 工厂关 | 岩浆间歇泉 + 滴落管道 + 底部熔融金属;**打掉另一关的 Boss 后整关的熔融金属冷却、间歇泉停止** —— 跨关卡的全局状态机关 | 我们的对应:打爆冷却塔/主控 → 全关卡热流停 → **同一张图二次通过时是另一副样子**,复用率极高 |
| **周期性火焰(大小周期)** | DKC《Oil Drum Alley》 | 油桶火焰有节律,火灭时才能踩;后段"火**通常只是变小,偶尔才全灭足够长**" | 关键是**双层周期**:小周期骗你、大周期才是真窗口。定时器用 `time-and-timers` 的 loop event 套两层 |
| **巨型活塞/钻头** | Metal Slug「Stamping Driller」;DKC Returns 管状机械 | 从墙里横向弹出,既是威胁也是**临时踏板**(弹出时可以踩着上高处) | 同压机,横向版;弹出瞬间给上边缘一条 oneWay solid |
| **起重吊臂/电磁吊钩** | Limbo 矿车段;工业关通用 | 吊臂横向搬运重物,玩家可以**站在被吊的货物上**过场;也能把货砸下来 | 吊臂 = 一条路径(`curves-and-paths`)上跑的运动学 solid;抄电梯的"先带乘客" |
| **碎料机/矿车轨道** | Limbo ch.28 结尾 | 推矿车到指定位置当踏板,车碾过按钮给轨道通电;跳到车前面、再把车推到轨道下当梯子 | 可推箱 = Matter 动态刚体已有(爆炸线做过);"车压按钮"= 传感器 |
| **三支线汇聚到一个总闸** | Half-Life《Blast Pit》 | 氧气 / 燃料 / 电力三个子系统分头去开,最后一起点火烧死巨型触手怪 | **这是"巨大设施"最好的关卡骨架**:巨物在场地中央全程可见,玩家绕着它跑三条支线,最后一个开关收网 |
| **机关改地形而非杀人** | Tomb Raider (1996)《Lost Valley》 | 找齐三个齿轮装上机器 + 拉杆 → 机器**关掉瀑布的水**,露出新路 | 我们可以做:关掉冷却水 → 水位下降露出下层通道(纯 solids 增删) |
| **垂直巨构造压迫感** | Portal 2 老光圈 | 把下一个房间**抬高**,让建筑对玩家有"支配性存在";悬在深坑里的巨球 | 我们的多层楼板结构天然适合:把风扇井做成贯通 3 层的竖井,每层都能看见同一台风扇的不同部位 |

## 3. 2D 横版的"巨物感"表现语法(重点)

### 3.1 尺度阈值 —— 大到什么程度会震撼,以及**大过头会失效**

gamedeveloper.com《Big And Scary》的两条核心结论:

- **套娃原则**:体型即威胁,是本能读数,不需要任何其他信息。比你大的 = 更强,比你小的 = 更弱。Gears of War 就是严格照这个排的:无武器怪 < 玩家 < 同武器敌人 = 玩家 < 稍强武器敌人(Kantor,或戴大帽子假装更大的 Theron)< Boomer(重武器)。
- **⚠️ 存在一个"太大就不吓人"的阈值**:体型超过阈值后,敌人**从战斗对手退化成环境危害**。原因:战斗语汇(格挡/反击/爆头/连段)全部失效;玩家反而变成主动进攻方(是你去找它,不是它来找你);它被打得血肉模糊死得很慢,而你是瞬间蒸发。原文:"打倒一个房子那么大的巨人很有成就感,但过程可能**没有跟同身高敌人对打紧张**。"

- **Little Nightmares 的甜点比例**:成人角色约主角**5 倍身高**,房间按"比她大很多倍的身体"建造。5× 是"压迫但仍读作生物/对手"的位置。

▸**落地(数值建议)**:玩家 30×88。
- **敌人**(要打的):上限 ≈ 88×5 = **440 px 高**(屏高 540 的 81%)。再大就该按机关做而不是按敌人做。
- **设施机关**(不是打的,是绕的):**放开手做 800~1600 px**,反正它本来就是环境。风扇直径 **540~800 px** 正好落在"整屏~1.5 屏"。
- **推论:用户想要的"巨大风扇"应该走机关线不是 Boss 线** —— 这也正好绕开了"太大反而不吓人"的坑。要震撼的 Boss,反而应该压在 300~440 px。

### 3.2 构图:只露一部分 / 延伸出屏幕

- **Babel 项目笔记**(2D 巨 Boss 实做复盘):战斗时 boss **大部分身体在屏幕外**;二阶段才 zoom out 揭示全貌,"让玩家感到渺小和无力"。**先藏后揭**比一开始就给全景震撼十倍。
- **分段骨架技巧**(参考 Metroid Fusion 的蛇形 Boss):身体切成若干段,每段有 start/end 关节;**只驱动头段**,后续段依次"旋转对齐 + 平移吸附"跟上。好处:巨大 + 流畅 + 美术只需画一段。
- **GB Studio 屏幕尺寸 Boss 的做法**(受限平台的极端解):Boss 本体画在**背景/overlay 层**(不是 sprite),另配一个不可见 sprite 做碰撞、每帧同步位置。启示:**巨物的"看"和"碰"可以完全分家**。

▸**落地**:这条我们有现成条件 —— 用户已确认"巨物可以是多贴图拼装 + 碰撞条目"。规则定死:
1. 视觉 = N 张切件拼(轮毂/叶片×k/外框/护网),各自 depth 不同;
2. 碰撞 = **只挂 3~6 条 solids 矩形**(轮毂柱 + 停位叶片),不要按贴图逐像素配;
3. 出场时故意让上下都出画,**只有玩家退到最远角落 + 镜头拉到 combatZoom 才勉强看全**;
4. 风扇轴心可以放在屏幕外(比如地板下方),画面里只有"上半个圆弧扫过" —— 看不见的部分由玩家脑补,这是最省成本的巨物感。

### 3.3 多层视差与前景遮挡

- 视差基本律:越远动得越慢(眼睛就是这么建构世界的);标准分层 = 前景 / 中景 / 背景 / 静态。
- **前景遮挡是巨物专用武器**:前景元素**部分挡住**巨物时,会造出"它延伸到画面之外"的错觉。前景层再加阴影/光照/粒子能进一步加厚纵深。

▸**落地**:风扇井里加 **2~3 层前景**(近处的护栏/管道/飘动尘埃,scrollFactor 1.2~1.5),让叶片从前景管道后面扫过。我们 `scene-fx-pipeline` 的动效层已经在做背景动效,加前景层是同一套方法。**成本极低、收益最大的一条。**

### 3.4 尺度参照物

巨物旁边必须有**已知尺寸的东西**当尺,否则大小无从判断。可用:玩家自己(玩家会拿自己当尺,所以别让玩家离巨物太远)、栏杆/梯级/门/管道法兰(有标准间距)、**被巨物碾过/吸进去的敌人尸体**、地面的巨物投影。

▸**落地**:①风扇护网做成**规则网格**(格子边长 = 玩家肩宽),网格越多层显得越大;②开场脚本让一个敌人被绞进去(§1.2④);③给风扇画一道**扫过地面的大投影**(`graphics` 一个半透明扇形跟着转)——投影是最便宜的尺度线索。

### 3.5 运动学:巨物该怎么动(CEDEC 2021,SotC/最后的守护者动画总监 Tanaka 五条)

1. **大质量可以突然停,但不能突然启动**;加速永远走平滑曲线。但**最高速不受限制** —— 巨物可以很快,只是不能瞬间变快。
2. 重力加速度与体型无关(是常数);重量 = 质量 × g,参考同尺寸真实生物定。
3. **单纯把动作放慢会丢失细节** —— 必须在**撞击瞬间把高频细节补回来**(震动、碎屑、扬尘)。只慢不补 = 显得假、显得轻。
4. 但震动/反应也**不能太快**,否则又变小了。
5. **巨物骗不了人**,任何穿帮立刻可见;用加法叠加层(additive layering)混合动画,别做快速动画切换。

▸**落地**:①风扇断电后**不是立刻停** —— 转速要用缓出曲线降 2~4 秒(`tweens` Cubic.easeOut),中间过零点前还要抖两下;②反过来,重新通电时**启动更慢**(4~6 秒爬到全速),这段时间就是玩家的逃生窗口(= Blast Pit 的核心张力);③压机砸地那一帧必须补:震屏 + 尘环粒子 + 碎屑 + 一次 hitstop。

### 3.6 音频:低频与次声

- 实证(Frontiers in Behavioral Neuroscience 2026,~18Hz / 75–78 dB):次声人**听不见但身体感知**,会显著**升高唾液皮质醇**、增加烦躁、让人把中性音乐评价为"更悲伤";受试者猜不出次声开没开(排除心理暗示)。19Hz 是常被引用的"闹鬼频率"。
- 次声研究者 Garcés 一句话点破本质:"能发出次声的东西**通常比我们更大更强** —— 听到它来了就是警告。"
- **Helldivers 2 音频的可抄规则**:按敌人**体型 + 危险等级缩放"重量感"**(脚步/武器/死亡爆炸全部更大更重);Hulk/坦克的素材取自**锈蚀船体和真坦克**;混音上用 HDR 优先级 + 动态 EQ,箴言是"**如果什么都在峰值,就没有东西是特别的**" —— 必须给巨物预留 headroom。

▸**落地**(我们是 Web Audio,别做真次声,浏览器/耳机放不出且没意义):
1. 风扇给一条 **30~60 Hz 的持续低频嗡鸣床**,音量随距离衰减 —— 玩家还没看见风扇就先"感觉到"它;
2. 巨物动作的低频要**给其它音效让路**:巨物发声时把枪声/脚步的低频段压 3~6 dB(简单 duck 即可),这就是 HDR 的穷人版;
3. 停机演出的重头戏是**声音**:嗡鸣频率下滑(pitch bend down)+ 轴承嘎吱 + 最后"咣"一声金属定位 —— 比任何视觉都更能让玩家确认"我做到了"。

### 3.7 镜头:震屏、拉远、hitstop

- **Trauma 震屏模型**(Squirrel Eiserloh, GDC 2016):维护 `trauma ∈ [0,1]`;受击 `+= 0.2~0.5`;随时间线性衰减;**实际位移 = trauma² 或 trauma³**(指数才有层次:trauma 0.30/0.60/0.90 → 震幅 3%/22%/73%);用 **Perlin 噪声**而不是随机数 —— 平滑噪声"感觉更好、自动兼容暂停与慢动作、频率可调、可重放"。2D 用**平移 + 旋转**,3D 只用旋转。
- **拉远揭示**(Itay Keren《Scroll Back》):Klonoa 遇 Boss 时镜头拉远,"要做什么一目了然";Yoshi's Story 把 Boss + 场地边界一起框进来。同文另一句要点:"**镜头与操作的脱节(震屏)传达出一种比玩家更强大的力量**"。
- **Vlambeer 31 条**里与巨物直接相关的:hit pause(sleep,命中瞬间冻帧)、镜头 lerp 滞后、镜头 kick(往开火反方向弹)、**更多低音**、永久性(残骸/烟雾滞留)。
- Limbo 的"小船段":从狭窄空间**切到大开阔空间**,把情绪冲击压缩进一个瞬间。

▸**落地**:①把 `ArenaScene.js:368` 那一处 `shake()` 升级成 trauma 模型(值域 + 平方 + 衰减),巨物事件加 0.6~0.9、普通枪击加 0.05 —— 有了指数曲线才分得出"大事"和"小事";②风扇入场/停机各安排一次**短暂 zoom out 到 0.85 再回弹**(我们已有变焦 lerp,只是换个目标值);③停机瞬间给 120~180 ms hitstop(`game.json.hitFeel` 已有 hitstop 基建,直接复用)。

### 3.8 巨物入场演出

从 Cuphead / Metal Slug / SotC 抽出的公共骨架:**预告 → 遮蔽 → 揭示 → 建立规则**。
- Cuphead:**每一个攻击都有预告**(动画 / 音效 / 甚至文字),**预告时长直接等于难度旋钮**;分阶段既延长了战斗又不重复,还制造"输了要从第一阶段重来"的赌注。
- SotC:每个巨像有开场演出提醒你它有多高;脚步的低音 + 蹒跚如行走的纪念碑 + 每一步的震屏 + 管弦乐,然后**镜头下摇到你身上**确立支配关系。
- Metal Slug 的做法(全系列通例):Boss 出现前先**锁屏**,把玩家关在一个固定舞台里,然后大家伙从画外开进来。

▸**落地**:风扇入场四拍 —— ①远处低频嗡鸣先起(玩家还在上一个房间)→ ②推开闸门,前景管道遮住大半,只见叶影扫过 → ③镜头 zoom out + trauma 0.7 震一下,全貌揭示 → ④脚本敌人被绞碎(建立规则 + 尺度参照)。我们的 `LockdownRoom` 已有"锁场"能力,可直接当 Metal Slug 式的舞台锁。

## 4. 空投 / 投放演出

### 4.1 案例

- **Metal Slug 3「Parachuetruck」**:节拍是**先降落伞炸弹齐射清场,再从车顶发射器弹射士兵下来"打扫残局"**。—— 轰炸是预告,投兵是正菜。
- **Metal Slug 1 的投弹直升机**:反复投弹,必须钻到它正下方朝上打;**五机编队里打掉红色长机,整队互撞**(给玩家一个"聪明解")。
- **Helldivers 2「Bot Drop」的完整节拍**(最值得抄):小兵掏信号枪 → **红色曳光弹升空(此时还能打断!)** → 曳光到顶 = 不可避免 → 运输舰飞入 → 悬停 → 投放 → 兵着地。附加规则:**运输舰必须在开始投放前打掉**才算拦截;打掉四个推进器中的任一个,飞船会砸在自己的载荷上一起爆炸。
- **Bug Breach 版本**:小虫**抬头尖叫 + 喷出棕色烟雾**(纯动画预告)→ 地面裂开涌出。
- **社区反馈(重要负面经验)**:玩家普遍抱怨"从音频提示开始到判定成立只有 ~1 秒,来不及反应",尤其 Hunter"看到起手动画时就已经晚了"。**预告窗口太短 = 玩家觉得不公平。**
- **Drop Pod 通感**(TV Tropes):落地本身就是伤害事件("Ground-Shattering Landing"),砸地顺便软化周围敌人。

### 4.2 可抄的节拍拆解(合成版)

| 拍 | 时长参考 | 内容 | ▸落地 |
|---|---|---|---|
| ① 预告音 | 800~1200 ms | 远处引擎/警报/低频渐强,**尚未有任何实体** | 只是一个音效 + HUD 边缘红色脉冲 |
| ② 可打断窗口 | **1500~2500 ms**(比 Helldivers 长!) | 曳光弹升空 / 舱门指示灯闪 —— **此时击杀信号兵或打掉运输机可取消** | 给玩家真的能打断的时间,这是 Helldivers 挨骂的地方 |
| ③ 阴影逼近 | 600~900 ms | 地面画一个**逐渐缩小、逐渐变深**的椭圆影(影子越小 = 越近) | `graphics` 一个椭圆 + tween scale/alpha,极便宜,读数极清晰 |
| ④ 砸地 | 1 帧 + 400 ms 余波 | trauma 0.8 震屏 + 尘环粒子 + 落点范围伤害 + 碎石 | 复用 `Explosives` 的范围伤害 + `FluidFx` 尘;箱体砸出的坑可以留成掩体(呼应"残骸保留碰撞") |
| ⑤ 静默半拍 | 300~500 ms | **什么都不发生** —— 这一拍是全场最关键的,给玩家喘和瞄 | 纯 delay。省掉这拍,整段会糊成一坨 |
| ⑥ 开箱前摇 | 500~700 ms | 锁扣依次弹开(咔、咔、咔)+ 液压泄压嘶声 + 箱门缝隙透出红光,箱体轻微鼓动 | 三声锁扣 = 三次极小震屏(trauma 0.1),做"倒数"用 |
| ⑦ 出怪 | — | 箱门砸开(再一次震屏)+ 怪物冲出;箱体空壳**留在场上当掩体** | 空壳 = 一条新的 solids 条目,直接改变了战场地形 —— 这是投放最有价值的副产品 |

▸**总落地**:整段 5~7 秒。用 `time-and-timers` 的链式 delayedCall 串起来即可;箱体本体走"多贴图拼装 + 单一碰撞条目";怪物从 `Drops`/敌人池里取。**空投能同时解决三件事:补怪、改地形、给巨物感 —— 性价比最高的演出。**

## 5. 建议的落地优先级(按"震撼/成本"排序)

1. **前景遮挡层**(§3.3)—— 一两张切件 + scrollFactor,立刻有纵深,零逻辑。
2. **Trauma 震屏模型 + 巨物 hitstop**(§3.6)—— 改一处 `shake()` 调用点,全局收益。
3. **低频嗡鸣声床 + 停机 pitch-down**(§3.6)—— 音频是巨物感最被低估的一半。
4. **巨型风扇机关**(§1):走"可击破配电柜断电"路线(复用 `cabinet` 联动),叶片停位插 solids 变平台,三档转速,开场脚本教学死。
5. **空投演出**(§4)—— 七拍模板,配合 `LockdownRoom` 做房间战开场。
6. **冲压机 / 传送带**(§2)—— 复用电梯的运动学 solid 搬运;传送带对**尸体**也生效,画面加分。
7. 熔炉全局冷却(§2)—— 做二周目差异化时再上。

**两条纪律:**
- 巨物的**看**与**碰**必须分家(§3.2)。视觉随便拼,碰撞永远是那几条矩形 —— 别让美术复杂度渗进物理。
- 观感改动**先建立事实基准再动手**(爆炸线的教训):做风扇前先录一段"现在的空房间"作对照,改完逐项对比,别凭感觉说"这样更震撼"。

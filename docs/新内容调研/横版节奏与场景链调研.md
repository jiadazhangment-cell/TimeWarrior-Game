# 2D 横版射击的场景链与节奏理论(救档全文)

> 调研日期 2026-07-27 深夜(子调查通知救档 2026-07-28,原文英文保留以防转译失真)。用途:基地章多区域推进线的节拍与过渡设计依据。母文档《同设施多区域差异术.md》已部分吸收,本文为完整原始报告。

## A. Multi-Region Stage Design (2D Run-and-Gun)

### A1. Metal Slug

**Stage structure pattern.** Every mission is a chain of 3-6 distinct scenery beats, never one biome:
- MS1 Mission 1: forest → river encampment → waterfalls → gunship-fortress ruins (boss)
- MS1 Mission 2: open ground → bridge → water/boats → freight train (boss on the moving train)
- MS1 finale: cliffs → bridge blown up mid-stage → plummet to submarine → shoreline → airport → final boss. **Scripted-destruction transition**: one explosion instantly reclassifies the space.

**Transition-device catalogue**: vehicle boarding/de-boarding as scene-change device (MS3 branching = different vehicle-scenery combos); **screen-lock arenas** (MSA Mission 5: lock at thresholds → paratroopers; boss arena physically changes mid-fight); environmental destruction (demolishing a house sends bricks+soldiers flying); elevators/lifts as vertical rooms with checkpoint before boss; branching paths to wholly different scenery.

**Developer commentary (shmuplations MS2 interview)**: variety was an explicit goal over single-region confinement; stage order was a production accident (Hong Kong stage meant to be Stage 1, desert shipped first because assets finished first); mechanic pivots force full stage re-art; small-team constraint named directly.

### A2. Contra

- Contra III: variety via **format switch** (4 side-scroll + 2 overhead stages), not just tilesets.
- Base/fortress interior beats reused across series: destroy-door entry, wall gun-panels, awkward staircases, "climb wall while snipers harass" gauntlet recurs almost verbatim in three games.
- Shattered Soldier Stage 1: vehicle-crash-through-windshield as instant "you are now inside" signal. Stage 2: motorbikes → warehouse → moving train (chained vehicle transition keeps side-scroll continuous).

### A3. Modern 2D — cheap biome variety

- **Dead Cells**: all textures painted grayscale, **gradient map recolors per biome** — swap gradient map, no redraw. Same props reused across biomes (palette+particles+lighting change only). Interiors=complementary palettes, exteriors=analogous. Parallax reuses same textures at different depth/opacity.
- **Blazing Chrome** (genre peer): *"backgrounds are the most time-consuming art assets"* — variety strategy = change the **mechanic/vehicle** per stage instead of new tilesets ("new place" read comes from new verbs as much as new pixels). Palette separation by function: environments toned-down, characters vivid. Recurring silhouette motifs (distant crashed battleships) stitch stages into one world cheaply.
- **Cuphead** (opposite pole): hand-drawn cost → shrink world count, front-load planning ("ideas have to be great because implementation is enormous").
- **Broforce**: destructible voxel terrain is the variety device; dormant enemies double as set-dressing.
- **Huntdown**: variety at the **faction level** (gang identity = signage/palette/silhouettes) over one consistent city palette.

### A4. Synthesis on art-pipeline cost

1. Grayscale-then-gradient-map is the cheapest "many areas, one paint pass" technique.
2. Spend unique-art budget on a **mechanic change** (vehicle/camera/minigame) rather than full new tileset.
3. Recurring silhouette/prop motifs stitch a world cheaply.
4. Background art (not characters) is the top cost driver in run-and-gun — treat backdrop budget as the priority constraint.

## B. Level Pacing & Transitional Spaces

### B1. Pacing theory

- Pacing must be **authored**; peaks/troughs model — *"it is the contrast between the two which makes the action riveting"*; pre-rank key events by impact, space them so peaks grow while troughs stay restful.
- **Level Design Book vocabulary**: beat / Pulse / Accent / Rest / Motif / Variation; **set piece** = especially elaborate beat with unique concept, high cost, unskippable — "design at least one set piece you genuinely want players to experience" (spend big on few, not evenly). Valve beat taxonomy: Explore / Combat / Choreography / Puzzle. Start each level low before ramping; avoid ending on the single highest-intensity moment (final boss should feel *inevitable*, not maximally hard). "Teach, Test, Twist" pattern.
- Withholding as pacing: Dead Space 2's Ishimura revisit holds back the onslaught ~15 min — dread from memory, no new mechanic.
- Horror version: *"there must always be a build up followed by a release"*; Dead Space named as failure case (never stops → dread never accumulates).
- Pete Ellis 3-act structure per level; **hard-gate** = section you can't return through, enabling "elegant downtime sections (rappels, lift rides)" — ties streaming to pacing downtime in one move.
- 机核「电子游戏中的节奏感」: fun is mostly 节奏; alternate fast-paced (quick feedback low load) vs slow-paced (deep systems); author's own 20-level game hit fatigue at 10-12, fixed with short no-timer relaxation stages + mechanically-different mini-levels every 4-5 stages.
- 开放→收束→开放 funnel cycle (Chinese GDC commentary): open exploration → funnel into high-quality combat → open release.

### B2. Transitional / decompression spaces

- **"Making Better Hallways"**: hallways are where streaming occurs AND natural pacing breathers — same design move. Upgrades: mid-hallway vista moment (remove wall/ceiling for sudden sightline); environmental-storytelling details in sightline.
- Valve placed level transitions "in down-time between combat and in a natural chokepoint" (Creative Airlocking).
- **Elevators as polite loading screens**: forced idleness that reads intentional; hard pacing break between encounter sets.
- **Vista theory**: deliberately low-intensity beat serving breather + wayfinding + foreshadowing at once; wow-moments kept infrequent (expensive + lose impact with repetition).
- indienova 关卡分类: 电梯/小路/车船 as connective devices — 让玩家情绪恢复平静,更容易营造下一次情绪体验.

### B3. Safe rooms

- **Blasphemous**: checkpoints ~one per area, never >7 screens apart (Dark Souls bonfire model). Single-use levers were a self-flagged mistake → reusable shortcuts (smashable glass one-way drops, permanent teleports/elevators). Bosses placed *next to* shortcuts. Hierarchy District > Zone > Scene.
- **RE7 safe rooms**: 制作人原意=紧张流程后有安全地方喘口气; RE save-room music's "objectively safe / subjectively unsettling" dissonance is deliberate.
- **RE4R**(gameres 长文): "精心编排的线性箱庭"; hub-and-spoke reuse (return to same hub from different directions = mental map + interconnection feeling despite linear structure); **combat rooms deliberately never back-to-back** — safe zones (storage/puzzle/merchant) interleaved as the rhythm-break mechanism; contrast TLOU's intentional 无用房间 (RE4R needs none because density stays high) — a sourced counter-argument worth weighing for run-and-gun where pace is genre identity.

### B4. Backtracking without filler

- Rule: *"only use backtracking if it buys a strong emotion or a truly unique challenge"* — never distance/padding alone. Bad example: Metroid Prime 3 forced backtracks with no new challenges.
- **Halo Flood corridor**: same geometry, entirely different encounter because the level's fictional state changed (infestation).
- Blasphemous shortcut evolution doubles as the definitive case study.
- Chinese Metroidvania theory: backtracking works when (a) semi-open world with ability-gates, (b) **distinctive doorway art as memory hook** ("I couldn't get through here" → want to return).

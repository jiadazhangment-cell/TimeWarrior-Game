# 工具与环境

> 记录本项目用到的所有工具:装了什么、什么版本、干什么用、为什么选它。新增依赖时更新此表。

## 运行环境
| 工具 | 版本 | 用途 |
|---|---|---|
| Node.js | v24.18.0(系统已有) | 运行构建工具与资产脚本 |
| Git | 系统已有 | 版本管理 + 原创性证据链 |

## 项目依赖(npm)
| 包 | 版本 | 用途 | 选型理由 |
|---|---|---|---|
| phaser | 4.2.1 | 游戏引擎(渲染/场景/输入/内置 Matter.js 物理) | 唯一官方为 AI 编程适配的引擎(自带 28 份 skill);内置物理免胶水 |
| vite | 8.1.4(dev) | 开发服务器 + 打包 | 热重载 ~200ms;产物纯静态适配 4399 |
| @resvg/resvg-js | dev | SVG → PNG(资产管线) | Rust 内核,零系统依赖,跨平台像素一致;比 Inkscape CLI 轻 |
| free-tex-packer-core | dev | 纹理图集打包(JS API,纯代码调用) | WebGL 批渲染必需;core 版无 GUI 依赖 |
| jsfxr | dev | 程序化生成短音效(枪声/爆炸/受击) | sfxr 的 JS 移植,参数化生成,免版权 |

## 常用命令
```bash
npm run dev      # 开发服务器 http://localhost:5173
npm run build    # 构建到 dist/
npm run preview  # 预览构建产物
```

## 资产管线(规划,脚本落地在 tools/)
SVG 部件(assets/svg) → resvg 批量转 PNG(按 1x/2x 两档分辨率) → free-tex-packer-core 打图集 → Phaser 加载。
注意:Phaser 载入 SVG 时即光栅化,"运行时无损缩放"不存在,清晰度靠按 DPR 出高分图集保证。

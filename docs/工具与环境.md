## 参考游戏本地分析台(tmp-cuts/pb2/,不入库)
《入侵者2》(Intrusion 2,4399 版 SWF)+ 自托管 Ruffle 模拟器——跑姿/下蹲的动画标杆,可逐帧冻结分析。
```bash
node tmp-cuts/pb2/server.mjs   # 起 http://127.0.0.1:8799/pb2.html
```
- 冻结取帧:evaluate 里 `window.__player.pause()/.play()`;隐藏遮罩 `#play-button{display:none}`(注意是连字符 ID)。
- 喂输入:对 `__player` dispatch 合成 KeyboardEvent(keydown 不发 keyup=长按)/PointerEvent(pointermove=瞄准)。
- 坑:4399 在线版 chkDomain.js 同步脚本挂死会阻塞整个渲染进程(灰屏+evaluate超时),所以本地化;Ruffle 的 canvas 渲染器不支持 BitmapData.draw,必须用默认 WebGL;SWF 下载需带 Referer 头。
- 未来敌人/怪物/BOSS 的动作参考同样用这套(逐帧看它的机甲/蜘蛛机器人)。

# 基地章推进线设计提案(v1,2026-07-28,待拍板)

> 起因:用户定版方向——"没那么快走出实验基地;地下城打完回地表解除封锁继续向前;基地其他场景+新机器怪(机械触手怪/重型装甲兵等);走出实验室前一场大混战(运输机空投集装箱,装着很大的机器怪);要有巨大设施(必须停下才能过去的巨型风扇等);参考 RE8 海森伯格工厂"。
> 调研依据(全在 docs/新内容调研/):RE8海森伯格工厂拆解 / 巨物机关与震撼感语法 / 同设施多区域差异术 / 横版节奏与场景链调研 / In2重装机甲Exoarmor全拆解 / In2入场演出与环境setpiece普查 / In2触手怪机器怪结构配方 / In2近战生物AI配方(§7 BOSS基建)。
> 待拍板项见 §九。

## 一、大结构

**第一幕=整个实验基地**(机器语法主场):地表走廊+地下蜂巢(已有)→ 解除封锁回地表 → **向右推进四个新区** → 出口大混战 → 冲出基地=幕终。生化怪与"截然不同场景"归第二幕(出基地后),原提案时相裂谷等章节顺延。

**世界观合法化**(Metroid Fusion BSL 空间站手法——与我们同题的最强先例):基地=按功能分区的设施,每区因功能而面貌不同,"同一设施"靠不变量层(走道带高度/舱门形制/警示灯语言/管线色标)锚死——**可信度来自功能标签+一致施工语言,不来自真实图纸**(黑山基地结论)。

## 二、全局地基(区域开工前先立,全线受益)

1. **红点弱点统一语言**(RE8 工厂的核心抄袭):设施机关(风扇轴心/配电柜/压机液压口)与机器怪(触手怪核心/重装兵胸炉/集装箱 BOSS 反应堆)共用**橙红发光端口**这一个弱点视觉——玩家学会"打红点"=同时学会解谜、开机关、杀怪。与既有"敌方科技统一色"原则合并成一条。
2. **区域档案表(Region Profile)**:把 `_drawHiveBackdrop` 的 `{tex, walkR, tint}` 扩成一行九字段 `{tex, walkR, tint, fogAlpha, dustDensity, lampColor, ambientKey, enemyMix, decorSet}`,新区=加一行+一张概念图,不加散落 if。
3. **明度纪律**:蜂巢四层 tint 实测明度全挤在 65-68%(换区感被吃掉的元凶)——新四区明度跨度拉到 50-80%(仓储压暗/动力提亮),至少一区饱和破 25% 当"色彩事件"。
4. **管线色标全局系统**(ANSI A13.1 真标准,室内元素库第 10 条升格):动力区黄/冷却绿/制造蓝/消防红——每区主色"设定内合法"。
5. **阈限三拍纪律**(每次换区必做):上一区末端塞两件下一区的预告物 → 过渡空间(管廊/电梯/闸门,现成件)→ 新区第一屏无敌人横推+镜头小幅拉远定场。
6. **trauma 震屏升级+低频声床**(巨物线地基,全局收益):`shake()` 升级为 trauma∈[0,1]+平方曲线+衰减(巨物事件 0.6-0.9/普通枪击 0.05,有指数才分得出大事小事);巨物给 30-60Hz 持续低频嗡鸣床(距离衰减,先闻其声);巨物发声时枪声低频 duck 3-6dB。
7. **SpawnController 波次系统**(In2 整体照搬,混战/封锁战复用):events 带+`PauseDelayedFunctionsUntilDefeated`(线性时间轴自动获得"打完才继续"语义);触发与入场解耦(keys 字典);`die_script/afterstart_script` 改 EventBus 事件。
8. **相机权重混合层**(演出基座,同时是 BOSS 变焦相机的实现基座):多镜头 weight 加权平均+梯形包络 SetFade,参数档位表直接抄 In2(小怪 0.1,0.5,1 / BOSS 0.25,0.8,1 FadeIn(30,1000))。

## 三、区域线(解除封锁→向右,四区+终局)

> 强度曲线:蜂巢(高)→管廊(低,清味剂)→动力(中高,机关主导)→制造(高)→仓储(中)→混战(最高)→出口(释放)。战斗房不相邻(RE4R 纪律);每区约一个安全屋(Blasphemous ≤7 屏);补给终端仪式(提案 v2 系统件)在本章首装。

### R-A 管廊夹层(过渡小区,成本极低)
蜂巢出口接窄管廊横推:极窄横向、无掩体、应急灯条——长直线火力压制的紧张小段。全用现有结构件。**职能=阈限**:黄色动力管线在此出现(预告)、远处低频嗡鸣渐强(风扇的声音先到)。

### R-B 动力涡轮区(巨物第一课)
主色警戒黄+弧光蓝白,全基地最亮最高对比;背景多层视差涡轮阵列+前景管道遮挡层(scrollFactor 1.2-1.5,成本最低收益最大的巨物感手段)。

**巨型风扇**(用户点名,直径 540-800px=整屏~1.5 屏,贯通 2-3 层的竖井,每层看见它不同部位):
- **三档转速**(六硬规则之"不完全停比完全停好玩"):全速(秒过不去,扇面伤害区+风力推挤)→ **卡停后仍挣扎**(轴承嘎吱+每隔几秒猛跳半格,玩家从叶缝穿过时心里打鼓)→ 彻底断电停死(叶片停位插 solids 变可站平台——看与碰分家,叶片不做旋转刚体,转动=纯贴图旋转+传感器)。
- **停机=打爆 2-3 个分散在不同高度的配电柜**(战斗解,`cabinet` 联动现成零新代码)或绕检修道按总控(操作解);风扇↔柜画**发光电缆连线**+柜亮红灯,因果可视。
- **教学脚本化**:入场时一个巡逻机兵被吸进去绞碎(零成本学会"碰不得"+尺度参照)。
- **二段用法**:风扇转动=上升气流把玩家/尸体/手雷托上高层平台;回头刷高处补给要重新启动风扇(用户要的"重新启动"张力);重启=4-6 秒慢爬全速,这段就是逃生窗口。
- 断电顺带=**全局 flag**(RE8 通电手法):区域照明转应急红、背景动效停、部分敌人休眠。
- 停机演出重头戏是声音:嗡鸣 pitch 下滑+轴承嘎吱+最后"咣"一声金属定位+120-180ms hitstop+trauma 0.7。

**新怪首秀:机械触手怪**(中型,悬挂式)——天花板轨道滑行的检修单元异化体:蛰伏(收拢贴顶)→警觉(展开垂下)→垂 2-3 条物理触手抓甩。结构=In2 FloatBot 配方机器皮(每触手 4 盒刚体→12 段 Catmull-Rom 渲染、关节马达=纯阻尼器、伸手反作用力拽动本体);弱点=胸腹**红色核心**(统一语言);断触手=独立血量(FloatBot 单触手 180)。三段式投放:动力区 1v1 教学→制造区加环境限制→混战当压力源。

### R-C 制造装配区(海森伯格工厂主场)
冷白顶棚工作灯+节拍性金属撞击音景;长向水平输送线+机械臂列+锻造熔炉橙红火光(与蜂巢冷色/动力黄都不同)。

- **传送带**:站上被动位移/逆行净损耗;**尸体也吃偏置**(尸体被流水线运走的画面=白送的巨物感+黑色幽默)。solid+接触速度偏置,低成本。
- **冲压机阵列**:时序穿越;其中一台整屏长跑不过去,**必须躲进压机自身凹槽**(DKC"压机的形状就是避难所"手法);压机=运动学 solid(电梯同款"先带乘客后挪"),压中=大伤害+击退非即死(射击游戏不做解谜式秒杀)。
- **环境叙事高光**:头顶输送链挂满**半成品机器人**列队驶过(可射断吊钩掉落——RE8 官方给成就的招);走廊放五只沉睡机兵只让一只醒(RE8);走到装配台,流水线上半成品**睁眼苏醒**=伏击波(SpawnController 波次)。玩家亲眼看到打了一章的敌人的产地。
- **新怪:重型装甲兵**(大型精英,1.7×玩家高)——**Exoarmor 配方直接抄**:两体两脚极简骨架(躯干多边形+髋圆 r20+双脚圆 r10+限位铰+双绳约束+PD 悬浮)、动画驱动脚 IK;**背刺 ×2 伤害**(走位动机一行换来);**肩挂导弹夹单点部位破坏**(独立 180HP、吸主机伤、爆掉再扣 200);剑三段帧表 AI 版(前摇 30f/发生 15f/判定 22f 关/后摇 28f)+齐射锁转身;AI 周旋-扫射-贴脸-挥剑状态机含"玩家举近战时自动拉开"。原提案"双刀+喷气+胸炮"的重装机兵设定并入:喷气突进=滑铲档,胸炮=胸口红点蓄能炮(弱点即炮口,开火时才露红点=风险窗口)。
- 敌人递进纪律(RE8 法则:**每档只加一个新变量**):巡逻机兵(基准)→护盾变体(遮挡弱点)→机械触手怪(垂直+抓取)→重型装甲兵(装甲+部位)→集装箱 BOSS(合并所有规则)。

### R-D 仓储装卸区(出口前厅)
大片暗区+稀疏点光+空旷混响(全基地最暗,与动力区明度两极);高货架峡谷立体战、堆垛集装箱(可推/可站)、龙门吊沿轨道吊运货箱(运动学 solid 路径,可站在被吊货物上);坠物与视线遮断。混编压力最大化(机兵+触手怪+重装兵)。出口大闸门在最右,亮红灯锁死——预告终局。安全屋(补给终端)在进区处。

### 终局 setpiece:装卸场大混战(用户点名的高潮)

触发=接近出口闸门→警报+LockdownRoom 式锁场(Metal Slug 舞台锁)。

- **空投七拍模板**(巨物机关调研 §4 合成版,整段 5-7 秒):①远处引擎低频渐强 800-1200ms → ②**可打断窗口 1500-2500ms**(运输机进场信号,打掉推进器=拦截,Helldivers 挨骂的"预告太短"反着改)→ ③地面椭圆影逐渐缩小变深 600-900ms → ④集装箱砸地:trauma 0.8+尘环+范围伤害,**砸出的坑与箱壳留场变掩体**(空投同时解决补怪/改地形/巨物感三件事)→ ⑤**静默半拍 300-500ms**(省掉这拍整段糊掉)→ ⑥开箱前摇:锁扣三连弹开(三次 trauma 0.1 倒数)+液压嘶声+箱缝透红光 → ⑦箱门砸开,BOSS 出场。
- **运输机**=In2 GrabberBoss VTOL 骨架:悬停开舱投放节拍(开舱 30f→投兵→关舱→**全灭才投下一波**,SpawnController 全灭门控);机体掠过头顶只露腹部剪影(巨物"只露一部分"构图,不交战)。
- **集装箱 BOSS=装配线原型机**(建议:原提案"重装机兵 BOSS"升格为它——未完成涂装的巨型机兵,双刀+喷气+胸炮设定保留):体量压在 **300-440px**(尺度阈值调研的硬结论:敌人超过 440px 会从对手退化成环境危害,巨物感留给机关);结构=Exoarmor 骨架放大+Danmaku 招式纪律(**阶段解锁递进**:教学段 2 招→+机动→+胸炮全开;100% 确定性 action 链;**防踩头/贴背白嫖的专门反制**);招式选择器=ProbabityChoose(BOSS 基建首用,配方在 In2近战生物AI配方 §7);双目标变焦相机(同 §7,min_scale 0.7+锁边界+长 FadeIn)。
- 混战编成:BOSS+重装兵×2+触手怪+空投增援波次;环境武器全开(气瓶殉爆链/龙门吊集装箱砸落/传送带)。
- **补遗定案(In2双BOSS与集装箱攻击补遗,2026-07-28)**:①开箱=**换体术**——实心集装箱刚体在开箱瞬间整体换成空壳平台并**继承线速度+角速度**,门板变金属残片飞出(不播动画,物理自然);②**每箱必带补给**(弹药+血包与怪同箱抛出)——开箱既是威胁也是补给站,混战的弹药经济由它闭环;③**波次门控=全灭或超时任一满足**(杂兵 ~3.3s/大型 ~8s 兜底),永不卡关;④**清场招**:场上物件>8 时 BOSS 亲手抹平台清垃圾,顺带给玩家一次无伤呼吸拍(性能保险+节奏喘息二合一);⑤落点预警=DangerMarker 式 24 帧(~800ms)前置标记+明确安全区。
- **胜利=闸门开,天光涌入**——全作唯一一次"人造光→自然光"色温转换,这张牌只在最后一屏打(色彩脚本收尾);走出基地,下一幕世界露一眼,章末结算。

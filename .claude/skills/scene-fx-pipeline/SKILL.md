# 场景与特效管线(时空战士)

## A. 场景美术(概念图直用背景)

- **出图配方**(ChatGPT,Claude 直驱): "横版2D射击游戏的室内场景概念图 + 场景内容清单(灯带/培养舱/舱门/全息屏/管线) + **侧视正交视角(无透视消失点,像2D游戏关卡横截面)** + 无人物无文字无水印"。一张 1672×941 概念图可直接当背景用。
- **集成**: 概念图 jpg(quality 84 控包体)整张做背景;**地板线对齐**(图内走道面 y≈655 × scale = 游戏地面 470,scale=470/655),横向按 bgW 平铺;tint 压暗(0x9096a0)保角色可读性。
- **地面不画盖板**: 露出概念图自带的"走道下机械带"(只描一条沿口亮线),天然的下层纵深;底部暗角 0.45。
- 素材一律登记 docs/素材许可.md(prompt/尺寸/用途)。

## B. 战场道具(掩体/障碍物)

- 设计原则(用户拍板): 地面不能空旷,战场=掩体蹲防+跳箱抢高点+平台立体机动。
- 出图: 同风格道具集合图,"浅灰纯色背景,多个独立物件分开排列彼此留白,顶部平整,正交侧视"。
- 切件: tools/cut-props.mjs(角色管线无关节简化版:多边形→泛洪→除尘→**透明边裁剪**→按玩法目标高度缩放)。
- **玩法尺寸规范**: 掩体箱高52=蹲姿(hitbox 52)完全遮挡;可跳上的箱/柜 ≤84(跳跃顶高>92);半掩体路障38(蹲下头顶仍露,逼走位);单向平台高22。
- 关卡接线: solids 条目带 `prop:"贴图名"` → 场景以 setDisplaySize(w,h) 渲染,**碰撞盒=显示盒**;单向平台=桁架贴图 tileSprite 只横向平铺(纵向 tileScale=(p.h*2)/纹理实高)。
- 敌人巡逻会被 solids 自然折返,布置时留意 patrol 区间与道具交叠(=有机收窄,可接受)。

## C. 背景动效层("能动的都要动",用户拍板)

- 实现: `_decorateBackdrop(bx, S)` 按**概念图源图像素坐标**定位,每份背景拷贝一套;depth 0.4-0.6(背景之上、暗角/玩法层之下)。
- 培养舱气泡: **环形贴图(px_bubble)+NORMAL 混合**(气泡是折射不是发光!)+alpha values [0,0.55,0.45,0] 淡入淡出+微横漂(speedX±1.2/accelerationX±1.8;**再大必漂出玻璃**——±9 曾在 4.2s 寿命里累积横漂 ~80px 穿壁,用户点名过)+**deathZone onLeave=实测玻璃内壁矩形**兜底(出玻璃即消亡)+寿命限制在舱顶前消散。发光点上浮≠气泡(用户点名过)。
- 全息屏: **屏幕内容本身动**,全部元素严格锁在**实测玻璃内框**(特效区盖到边框/墙上立刻穿帮)——CRT 扫描线(px_scanline tileSprite,tween tilePositionY)+数据柱状图**逐根叠在画中柱上**(xs=逐列亮度扫描实测的柱心列表;按区间均分宽柱必与画中柱错位叠影,用户点名过)+雷达扫掠线(圆心/半径实测,长度<画中圆环半径)+能量核呼吸光(px_glow 同位叠加,scale/alpha 同步 yoyo)+受损瞬闪(独立叠加 rect,别和呼吸 tween 打架)。越界扫描白条=灾难(用户点名过)。
- **动效坐标校准法(定位铁律)**: 源图程序化测量(逐列/逐行亮度扫描找特征)定初值 → **游戏内按世界坐标画调试十字/矩形叠对艺术图**核准(消灭截图换算误差,±2 源图px 内收工) → 删调试层。"大概在那"的叠加动效比不动更糟。
- 警示红灯: **双层软光**(px_glow 径向渐变:大而虚光晕+小亮核,同相呼吸,错开各灯周期1.5-2.3s)。实心圆片=糙。
- 顶灯带: 轻微亮度浮动+单根偶发"日光灯失稳"三段骤闪(6-15s一次)。

## D. 光效质感三要素(项目美术原则)

> **光效质感 = 贴图形状(渐变/环/星芒/羽流) × 混合模式(发光ADD/折射NORMAL) × 生命曲线**。圆片+ADD 只是"会亮",不是"像光"——圆片充数禁令。

- 程序化贴图库(BootScene.create): px_glow(canvas radialGradient 软光晕)/px_bubble(亮环+高光点)/px_muzzle(星芒)/px_plume0-2(枪口羽流3变体,多椭圆叠白→黄→橙渐变)/px_scanline/px_spark/px_debris/px_flash。
- **枪口焰=拟真复合体,每发随机**: 白黄亮核(px_glow)+多瓣火舌羽流(3变体随机选形/上下翻转/缩放抖动/±4°/18%概率大焰,origin 左端=枪口沿射向)+制退器十字侧刺(低透明)+3-4粒锥形火星(±14°,带微坠)+橙色环境光晕;70-100ms 分层消散。**"每发混沌不同"=真实感核心,单一形状必单调**(用户点名过)。fx.muzzle(x,y,angle,tint),敌方橙色 0xffa64d。
- 断肢电光=px_glow 软光晕(flashEmitter)。

## E. 通用坑

- 玩家落地**不震屏**(质量感不匹配);震屏留给未来大体积 BOSS(后备清单)。
- 性能测量: 泵帧/遮挡下 FPS 表是节流假象,用"手动 loop.step N 帧计墙钟"(当前全场景能力 651fps,动效层开销可忽略)。
- 4399 包体: 大图转 jpg;发布前跑 build 看产物体积。
- 出图后原图下载: 滚到 ChatGPT 会话真底部按文件 ID 取(虚拟列表坑),页面内 fetch→base64→evaluate filePath 落盘。

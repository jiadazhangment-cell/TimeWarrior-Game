# 场景与特效管线(时空战士)

## A. 场景美术(概念图直用背景)

- **出图配方**(ChatGPT,Claude 直驱): "横版2D射击游戏的室内场景概念图 + 场景内容清单(灯带/培养舱/舱门/全息屏/管线) + **侧视正交视角(无透视消失点,像2D游戏关卡横截面)** + 无人物无文字无水印"。一张 1672×941 概念图可直接当背景用。
- **集成**: 概念图 jpg(quality 84 控包体)整张做背景;**地板线对齐**(图内走道面 y≈655 × scale = 游戏地面 470,scale=470/655),横向按 bgW 平铺;tint 压暗(0x9096a0)保角色可读性。
- **地面不画盖板**: 露出概念图自带的"走道下机械带"(只描一条沿口亮线),天然的下层纵深;底部暗角 0.45。
- 素材一律登记 docs/素材许可.md(prompt/尺寸/用途)。

## B. 战场道具(掩体/障碍物)

- 设计原则(用户拍板): 地面不能空旷,战场=掩体蹲防+跳箱抢高点+平台立体机动。
- 出图: 同风格道具集合图,"浅灰纯色背景,多个独立物件分开排列彼此留白,顶部平整,正交侧视"。
- **挡路装置(门/栅栏/闸)必须要"侧棱视图"**:侧视游戏里挡左右通行的物体,玩家看到的是它的**边缘窄面**,不是正脸——prompt 必须明说"玩家从左右通过,看到的是侧棱/边缘,不是正面",否则 AI 默认给面向镜头的正视图(闸门返工教训,用户点名过)。
- **结构件(隔墙/立柱/门塔)也禁止程序化凑合**:样式化的矩形+线条仍被用户点名"像没贴图的白模",一律出图切件(参考19 隔墙截面柱先例)。
- 机关件切件母本清单:参考16(正脸门件转背景装饰备用/操作台/信标柱/激光柱对)、参考17(闸门侧棱三件,现役)、参考18(壁挂炮塔基座+枪体)、参考19(隔墙截面柱)——脚本 tools/cut-devices.mjs(支持 per-item src 与 erase 挖洞;门框类"回字形"件的除尘=保留全部≥2%面积连通块)。
- **装置出图=先设计真机械(2026-07-16 制作哲学定版)**:prompt 里写全结构件清单(框/厚度/铰点/收纳槽/支撑/缆绳),按"顶面/立面/支撑三件套+微俯视投影(与走道带一致)"描述;**使用场景必须写进 prompt**(如"侧视游戏,玩家从画面左右走进电梯,厢体左右无门"——参考21 先例);开放式/镂空结构切件开 **clearPockets**(角柱顶棚围死的画布底色泛洪清不到,按连通块面积清除)并数残留亮像素验收。
- **剖面件出图法(暗门v4定版,"地下结构可见化"的通用解)**:装置藏在地面/墙体内的部分,专门出"剖切图"件(甲板切断面+剖开的空腔内壁+支撑构件),贴在走道前立面带([486..544])里;运动件配"侧面断面条"与顶视件同 tween 平移——藏起来的机构在断面里亲眼可见,遮挡把戏一律不许。prompt 关键词:"正视剖切图/被剖开的空腔/切断面"。
- **切件新选项**:rotate 任意角(斜梁母本自带倾角→转平再平铺,转后自动重找内容盒)+insetX(任意角旋转把原裁切边变成斜切口,左右内缩到满高区,平铺件端头必须齐整)+**家具类必开 clearPockets**(腿间/层间/臂下围死的画布底色泛洪清不到,长凳曾 30% 亮像素发白上屏)。
- **模块化拼装优先于整图拉伸**:母本比例与游戏需求差太多时(井口框 2:1 vs 需 5:1),按结构拆件重组(框环/槽床/滑板各自切)——入侵者2 的 2629 张模块位图就是这个思路;整图硬拉伸=细节全糊。
- **室内出图先查 docs/室内设计元素库.md**(88 条调研元素+出图/切件/光效分工):实验室大厅配方=贯层巨型标本舱锚点+顶部玻璃观察走廊+低温舱列(留破裂空格=叙事)+管线桥架+吊装轨道+冷青主调局部警戒红+"走道面在画面下三分之一(与走廊图同构,便于地板线拼接)"(参考20 首发即中)。
- 切件: tools/cut-props.mjs(角色管线无关节简化版:多边形→泛洪→除尘→**透明边裁剪**→按玩法目标高度缩放)。
- **玩法尺寸规范**: 掩体箱高52=蹲姿(hitbox 52)完全遮挡;可跳上的箱/柜 ≤84(跳跃顶高>92);半掩体路障38(蹲下头顶仍露,逼走位);单向平台高22。
- 关卡接线: solids 条目带 `prop:"贴图名"` → 场景以 setDisplaySize(w,h) 渲染,**碰撞盒=显示盒**;单向平台=桁架贴图 tileSprite 只横向平铺(纵向 tileScale=(p.h*2)/纹理实高)。
- 敌人巡逻会被 solids 自然折返,布置时留意 patrol 区间与道具交叠(=有机收窄,可接受)。

## C. 背景动效层("能动的都要动",用户拍板)

- 实现: `_decorateBackdrop(bx, S)` 按**概念图源图像素坐标**定位,每份背景拷贝一套;depth 0.4-0.6(背景之上、暗角/玩法层之下)。
- 培养舱气泡: **环形贴图(px_bubble)+NORMAL 混合**(气泡是折射不是发光!)+alpha values [0,0.55,0.45,0] 淡入淡出+微横漂(speedX±1.2/accelerationX±1.8;**再大必漂出玻璃**——±9 曾在 4.2s 寿命里累积横漂 ~80px 穿壁,用户点名过)+**deathZone onLeave=实测玻璃内壁矩形**兜底(出玻璃即消亡)+寿命限制在舱顶前消散。发光点上浮≠气泡(用户点名过)。
- 全息屏: **屏幕内容本身动**,全部元素严格锁在**实测玻璃内框**(特效区盖到边框/墙上立刻穿帮)——CRT 扫描线(px_scanline tileSprite,tween tilePositionY)+数据柱状图**逐根叠在画中柱上**(xs=逐列亮度扫描实测的柱心列表;按区间均分宽柱必与画中柱错位叠影,用户点名过)+雷达扫掠线(圆心/半径实测,长度<画中圆环半径)+能量核呼吸光(px_glow 同位叠加,scale/alpha 同步 yoyo)+受损瞬闪(独立叠加 rect,别和呼吸 tween 打架)。越界扫描白条=灾难(用户点名过)。
- **动效坐标校准法(定位铁律)**: 源图程序化测量(逐列/逐行亮度扫描找特征)定初值 → **游戏内按世界坐标画调试十字/矩形叠对艺术图**核准(消灭截图换算误差,±2 源图px 内收工) → 删调试层。"大概在那"的叠加动效比不动更糟。
- 警示红灯: **双层软光**(px_glow 径向渐变:大而虚光晕+小亮核,同相呼吸,错开各灯周期1.5-2.3s)。实心圆片=糙。
- 顶灯带: 轻微亮度浮动+单根偶发"日光灯失稳"三段骤闪(6-15s一次)。

## D. 光效质感三要素(项目美术原则)

> **光效质感 = 贴图形状(渐变/环/星芒/羽流) × 混合模式(发光ADD/折射NORMAL) × 生命曲线**。圆片+ADD 只是"会亮",不是"像光"——圆片充数禁令。

- 程序化贴图库(BootScene.create): px_glow(canvas radialGradient 软光晕)/px_bubble(亮环+高光点)/px_muzzle(星芒)/px_plume0-2(枪口羽流3变体,多椭圆叠白→黄→橙渐变)/px_scanline/px_spark/px_debris/px_flash。
- **枪口焰=拟真复合体,每发随机**: 白黄亮核(px_glow)+多瓣火舌羽流(3变体随机选形/上下翻转/缩放抖动/±4°/18%概率大焰,origin 左端=枪口沿射向)+制退器十字侧刺(低透明)+3-4粒锥形火星(±14°,带微坠)+橙色环境光晕;70-100ms 分层消散。**"每发混沌不同"=真实感核心,单一形状必单调**(用户点名过)。fx.muzzle(x,y,angle,tint),敌方橙色 0xffa64d。
- 断肢电光=px_glow 软光晕(flashEmitter)。
- **爆炸 v6 定版(2026-07-25 第四次点名后重构;v5 被点名"击中部位周围突然出现3个火球,根本不是正常的爆炸")**:v5 病根=碎火团卫星在爆心**周围**(r0 6-18px)定点 alpha 淡入,火是"冒出来"不是"炸出来"。**v6 结构(fx.explosion,RPG power0.9/气瓶 power1 共用)**:①核闪+星芒(不变)②**主火球从爆心猛然膨胀**——fx_boom 帧2(圆形湍流火团)双层错相(翻转+旋转差 2.3rad+时长差 150/205ms+反向漂旋,破"单贴图图章放大"),scale 0.06→0.48×power,**Expo.Out=前50ms完成七成膨胀的"炸"感**,ADD 双层叠加中心自然过曝=白热核;alpha 在 dur×0.72 后 Quad.In 熄灭③**边缘碎裂 4-6 团**:出生在爆心(±4px)延迟30-100ms,**Quint.Out 甩到 34-84px 外**(继承爆压极高初速急减速)+热浮力上飘-12px,scale 0.04→0.12-0.19(**远小于主火球=读作碎片,不是并列火球**)④主烟团 4-5 盖过火(不变:alpha 0.75/提亮 tint,火灭烟还在)⑤地表白尘环+熏黑(贴地爆专属)⑥罐体两半壳 Matter 对飞留场+火舌球×3 扇形(Explosives 侧,不变)⑦余烬 16-24+震屏衰减。仍守铁律:**火短促、烟主导、无蘑菇茎、绝不整段播片**;每发不同=随机(旋转/翻转/碎片方向/错峰)。验收法=真实 rAF 定时 renderer.snapshot 连拍(16/70/200/650ms 四时刻:核闪起球/连贯膨胀/碎片径向飞散/纯烟上升)。**In2 一手参数存档**(pb2-scripts 反编译):atmosphere_boom 矢量clip=闪(1-5)→火(6-12)→烟(13-41);主体只播烟段15-38@0.9,卫星整段1-41@0.6-0.7 随机转+阻尼外漂(0.94)+微升;FlameBall=物理圆体逐帧×1.025膨胀+碰面反弹+随速拉伸;两半壳速度15/frame 自旋±20,COLLIDE_NO_DAMAGE_HERO。(fuel 烧尽不炸机制已于 07-24 移植。)
- **燃气喷射火焰(泄漏气瓶,2026-07-24 重做;用户点名"清一色发白光、像天上的星星一闪一闪、这么粗糙的吗")**:病根不是配色而是**拿错元件**——喷焰一直在用 `sparkEmitter`(子弹打金属的蓝青白火花)+`fx.flash`(冷蓝辉光),每帧丢一颗 6px 小点=星星点点。**"火星必须暖色专属、勿借用蓝青 sparkEmitter"这条铁律要贯穿全部火焰场景,不只是爆炸那一处**(爆炸改了、喷焰漏了=同一个错误犯两次)。定版三件套,缺一不可:①**贴喷口的定向火舌**(双层:橙外焰 `px_plume`+暖黄内焰核,同轴独立抖动;每帧换变体/抖幅/上下翻转=湍流,**单层=一团色块,静态=贴纸**)②**甩出去的短命火团**(走物理路径 `_spawnFlame`,0.16-0.28s,小重力=湍流尾)③**烟迹**(飞行轨迹读得出来)。配套:熄火喷嗝=暖色余烬(emberEmitter),点燃音从 `laserSnap`(电噼声)换成 `Sfx.gasIgnite`(闷响+嘶嘶)——**音效同样有"拿错调色板"的问题,一并查**。
- **不同东西爆炸不同(用户定版方向)**:爆炸按对象设计档案——先问"现实中它怎么爆",再翻 In2 同类代码对标,最后转译到我们的画风。丙烷罐=上条;配电柜=电弧+火花无火球(已有);未来弹药箱=连串脆闪殉爆、燃料管=喷射火舌。**禁止一套火球通吃**。
- 旧配方历史坑存档(仍有效):canvas 画瓣渐变与椭圆必须同用绝对坐标(translate 后渐变锚偏=全透明);loop.sleep/wake 污染补间时钟(冻帧检视要用刚 reload 的干净实例);emberEmitter 暖色专属勿借蓝青 spark。

## E. 通用坑
- **public/ 静态资源被同名替换后,浏览器可能缓存旧文件**(占位图先行防 404 策略必踩):验收前必须 ignoreCache 硬重载——fx_boom 占位黑图被缓存导致"火球隐形"(帧中心亮度实测 0),普通 reload 不换。
- **遮挡态截图**:窗口被盖+loop.sleep 时 CDP captureScreenshot 等不到帧会 120s 超时——改 `renderer.snapshot(cb)+loop.step(now+0.001)` 微步进触发一次渲染(时间推进忽略不计),dataURL 经 evaluate filePath 落盘再解码看图。
- **入侵者2 特效解剖直通道**:`ffdec.bat -export script 目录 commando3.swf`(1505 个 .as,PropaneTank/Explosion/Particle/FlameBall 全在);矢量clip 帧序列=先在 swf_body.bin 里扫 `类名\0` 前2字节拿 charId,再 `-select id -format sprite:png -export sprite`(**-select 约束不住会导全部 sprite,导到目标出现就手动停**)。视觉件多为矢量clip 不在位图库里,别只翻 ffdec-test png。
- **scrollFactor(0) 只免滚动不免变焦**(R3 动态变焦实案):镜头 setZoom 会把屏幕 UI 从画面中心向外推(zoom1.07 时 HP 条直接被推出屏)。定式=屏幕件全挂一个 root 容器,每帧 `root.setScale(1/z).setPosition(480*(1-1/z), 270*(1-1/z))` 逆补偿(Hud/ThreatMarkers 已用);全屏色罩(封锁红光)不参与补偿,直接把尺寸放大到 1200×700 超采覆盖;开场遮罩期间不启动变焦。新屏幕空间元素一律进 root,别单独 setScrollFactor(0) 裸放。

- 玩家落地**不震屏**(质量感不匹配);震屏留给未来大体积 BOSS(后备清单)。
- 性能测量: 泵帧/遮挡下 FPS 表是节流假象,用"手动 loop.step N 帧计墙钟"(当前全场景能力 651fps,动效层开销可忽略)。
- 4399 包体: 大图转 jpg;发布前跑 build 看产物体积。
- 出图后原图下载: 滚到 ChatGPT 会话真底部按文件 ID 取(虚拟列表坑),页面内 fetch→base64→evaluate filePath 落盘。**新鲜生成的 estuary 资产可能 503 长达 10-20 分钟**(基建抖动期整单生成还会失败,消息里出现"再试一次"按钮=点它重试):下载梯队=会话 img src 同源 fetch → 库存 API `/backend-api/my/recent/image_gen`(带标题,可确认文件 ID→图对应关系,防错拿旧图)拿新签名 URL → 都 503 就隔几分钟再试;img 若已在 DOM 加载成功,canvas.drawImage 同源抽取零网络最稳。**按 ID 对号前先核 MD5/字节数**,防把虚拟列表里残留的旧图当新图落盘(参考25/28 错拿一例)。
